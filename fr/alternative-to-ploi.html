Le gratuit, open-source Ploi alternative

Comparaison mise à jour le 4 août 2026 · reflète les prix/fonctionnalités actuels de Cipi 5 et de Ploi

Cipi offre le même workflow d'hébergement Laravel en une seule commande que Ploi.io : déploiements sans interruption, Laravel Octane, files d'attente, SSL, bases de données - mais c'est 100 % gratuit, open source (MIT), fonctionne entièrement sur votre VPS Ubuntu et n'a pas déployer des limites. Échangez le GUI contre un contrôle complet du CLI et une automatisation native de l'IA.

Pourquoi les développeurs passent de Ploi à Cipi

Pas de frais mensuels

Ploi facture 8 à 30 €/mois par serveur. Cipi est gratuit pour chaque serveur, pour toujours : aucun niveau de forfait, aucune mise à niveau.

Aucune limite de déploiement

Cipi ne limite jamais la fréquence de déploiement. Diffusez autant de versions que vous le souhaitez sur toutes vos applications et serveurs.

Aucune dépendance SaaS

Ploi contrôle vos serveurs depuis son panel. Cipi vit sur votre VPS et continue de fonctionner même si vous n'avez pas accès au panneau Internet.

Open source et auditable

Sous licence MIT – lire, auditer, fork et modifier. Ploi est un SaaS à source fermée.

IA native avec double MCP

Les serveurs MCP par application et globaux permettent une gestion complète de l'infrastructure basée sur l'IA à partir de n'importe quel IDE ou agent compatible MCP.

Chiffrement au repos + souveraineté

Toutes les configurations sont chiffrées avec AES-256-CBC sur votre VPS, et la synchronisation du serveur chiffré intégrée permet un basculement automatisé.

Laravel Octane (FrankenPHP)

Créez ou convertissez vos applications avec cipi app create --octane / cipi app convert --to=octane. Faites tourner Octane à côté des applications FPM classiques, avec Horizon et Reverb pris en charge nativement — sans aucun panneau SaaS.

Facultatif PostgreSQL

MariaDB par défaut ; installez PostgreSQL en une commande et choisissez le moteur application par application (cipi db install pgsql).

Installer Cipi en une seule commande

Lancez un VPS Ubuntu neuf, puis exécutez :

wget -O - https://cipi.sh/setup.sh | bash

Cela installe et configure toute la stack de production — Nginx, PHP-FPM / Laravel Octane, MariaDB, PostgreSQL en option, Redis et Supervisor. Voir le guide de démarrage.

Où Ploi est toujours le meilleur choix

Ploi est basé dans l'UE (Pays-Bas) et est nativement conforme au RGPD, avec un site Web soigné GUI et une surveillance intégrée et DNS gestion. Si vous souhaitez une expérience visuelle de type Forge à un prix inférieur et que vous n'avez pas besoin CLI-first automatisation de pipeline ou intégration d'IA, Ploi est une option intéressante.

Comment migrer de Ploi vers Cipi

Passer de Ploi à Cipi est un basculement net plutôt qu'une conversion sur place : vous êtes debout nouveau serveur à côté de votre configuration actuelle, déployez à partir du même référentiel Git et changez DNS lorsque tout se vérifie. Votre base de code Laravel n'a pas besoin d'être modifiée.

  1. Faites l'inventaire dans le panneau Ploi. Répertoriez vos sites, démons, tâches cron et bases de données afin de pouvoir les recréer sur le nouveau serveur, et gardez Ploi actif jusqu'à ce que la transition soit terminée.
  2. Provisionnez un VPS Ubuntu neuf et installez Cipi. N’importe quel fournisseur convient (Hetzner, DigitalOcean, Vultr, Linode, AWS). Sur Ubuntu 24.04/26.04, lancez wget -O - https://cipi.sh/setup.sh | bash et la stack de production complète — Nginx, PHP, MariaDB, Valkey, Supervisor — est configurée en quelques minutes.
  3. Recréez chaque application et branchez Git. cipi app create provisionne une application isolée avec son propre utilisateur système, sa base de données, son pool PHP et son vhost Nginx (ajoutez --octane pour Laravel Octane). La connexion de GitHub ou GitLab configure automatiquement les clés de déploiement et les webhooks pour des déploiements sans interruption.
  4. Migrez les données et basculez. Importez votre dump de base de données, reprenez vos .env valeurs, émettez des certificats HTTPS avec cipi ssl install, puis faites pointer le DNS vers le nouveau serveur et mettez l’ancienne installation hors service.

Cipi s’appuie sur les conventions standard de Nginx, PHP-FPM / Laravel Octane et Deployer : aucune configuration propre à un fournisseur ne restera à défaire plus tard. Tous les détails dans le guide de démarrage.

Questions fréquentes

Existe-t-il une alternative gratuite à Ploi ?

Oui. Cipi est une alternative gratuite, open-source (MIT) et self-hosted à Ploi.io. Il installe et gère une stack de production Laravel complète sur n'importe quel VPS Ubuntu sans abonnement mensuel, sans frais par serveur et sans limites de déploiement.

Quelle est la différence entre Cipi et Ploi ?

Ploi est un panneau de gestion de serveur SaaS avec un GUI raffiné qui commence à environ 8 €/mois par serveur. Cipi est un open-source CLI gratuit qui s'exécute entièrement sur votre VPS et ajoute un REST API, un double serveur MCP pour les agents IA, un chiffrement de configuration AES-256 au repos et une synchronisation serveur à serveur intégrée.

Cipi a-t-il des limites de déploiement comme certains niveaux gratuits de style Ploi ?

Non. Cipi n'a aucun quota de déploiement ni aucune limite d'aucune sorte. Vous pouvez déployer aussi souvent que vous le souhaitez, sur autant de serveurs et d'applications que vous le souhaitez, gratuitement.

Quand dois-je encore choisir Ploi ?

Choisissez Ploi si vous souhaitez un site Web raffiné GUI, une surveillance et une gestion DNS intégrées, ainsi qu'une expérience de type Forge à un prix inférieur, et vous n'avez pas besoin d'une première automatisation de pipeline ou d'une intégration d'IA de CLI.

Puis-je migrer de Ploi vers Cipi ?

Oui. Provisionnez un nouveau VPS Ubuntu, installez Cipi avec une seule commande, recréez chaque site avec la création d'application cipi, connectez votre référentiel GitHub ou GitLab pour des déploiements sans interruption, importez votre vidage de base de données, puis pointez DNS sur le nouveau serveur. Votre base de code Laravel elle-même ne nécessite aucune modification.

Cipi dispose-t-il d'un tableau de bord Web comme Ploi ?

Oui, en option. L'exécution de cipi gui yourdomain.com installe un panneau de contrôle Web gratuit self-hosted qui gère un ou plusieurs serveurs Cipi à partir du navigateur : applications, bases de données, SSL, déploiements et logs. Contrairement à Ploi, le tableau de bord est opt-in et fonctionne sur votre propre infrastructure ; Cipi reste entièrement utilisable en CLI uniquement.
