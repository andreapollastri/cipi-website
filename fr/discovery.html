Octane sur FrankenPHP.
Ou FPM classique. Votre appel.

Chaque application sélectionne son moteur avec un seul indicateur : Laravel Octane exécuté sur FrankenPHP conserve votre application démarrée en mémoire et traite des milliers de requêtes par seconde - ou choisissez solide comme le roc PHP-FPM quand le classique est ce dont vous avez besoin. Derrière, MariaDB ou PostgreSQL par application et Valkey par portion cache, sessions et files d’attente directement depuis la mémoire. Les performances ne sont pas un niveau payant ici. C'est l'installation scénario.

FrankenPHP Laravel Octane PHP-FPM MariaDB PostgreSQL Valkey

git push.
C'est tout le pipeline.

Connectez GitHub ou GitLab une fois et Cipi s'occupe du reste : déployez les clés générées et injectées, les webhooks créée, chaque application est dotée de son propre utilisateur Linux, de sa base de données, de son hôte virtuel et de son pool PHP-FPM. Poussez vers votre branche et un déploiement sans temps d'arrêt avec signature vérifiée s'exécute en arrière-plan - avec une seule commande restauration si jamais vous en avez besoin. Pas de CI/CD à entretenir. Pas de pipeline YAML sur lequel pleurer.

Comment fonctionnent les déploiements
YAML
cipi.yml

Configuration qui voyage avec le code.

Committez un fichier à côté de l'application : alias de domaine, version PHP et php.ini, bases de données supplémentaires, workers de file ou Horizon, Laravel Reverb, le scheduler, un healthcheck et des profils de sauvegarde. Générez-le depuis le serveur, inspectez le plan, appliquez-le — ou activez l'opt-in pour que chaque déploiement réussi soit réconcilié. Le schéma ne contient aucune commande shell ; un fichier invalide est rejeté en entier, jamais appliqué à moitié.

generate plan apply auto on deploy

Files d'attente, websockets, cron.
Déjà en marche.

Les travailleurs de file d'attente Horizon ou simples s'exécutent sous Supervisor et redémarrent automatiquement à chaque déploiement. Laravel Reverb pousse les websockets en temps réel via Nginx avec SSL. Le planificateur est câblé en cron au moment l'application est créée. Les tâches en arrière-plan, les diffusions et les tâches planifiées ne sont pas une réflexion secondaire : elles sont partie de l'approvisionnement.

AI
IA native

Votre IA a un ligne d'assistance à la production.

Le serveur MCP intégré connecte Cursor, VS Code ou Claude Desktop directement à votre application en direct via HTTPS. Posez des questions en langage naturel : lisez les journaux, exécutez des requêtes SQL, exécutez artisan commandes, déclenchez se déploie. Les instructions destructrices sont bloquées, aucune session SSH ne s'ouvre jamais et vous ne collez jamais de pile tracez à nouveau dans une fenêtre de discussion.

santé app_info journaux db_query artisan déployer
Rencontrez le serveur MCP
Coffre-fort
Forteresse

Durci avant votre première connexion.

Authentification par clé SSH uniquement, Fail2ban avec interdiction progressive, pare-feu UFW, sécurité sans surveillance mises à niveau, un coffre-fort AES-256 pour chaque identifiant, une conservation des journaux conforme au RGPD et un accès complet aux utilisateurs Linux isolement par application. Des alertes par e-mail se déclenchent en cas de tentatives d'intrusion, d'élévations sudo, de modifications de clé SSH et échecs de déploiement, tandis que tout atterrit dans un journal des événements inviolable. La sécurité n'est pas une fonctionnalité que vous activer. C'est la valeur par défaut que vous devrez supprimer.

Synchroniser
Résilience

La perte d'un serveur vous coûte cher une commande.

Code, base de données, .env et stockage — chiffrés et expédiés vers n'importe quel compartiment compatible S3 dans les délais. Restaurez une base de données dans une commande, restaurez une version dans une autre. Et quand il est temps de migrer ou récupérer, cipi sync clone des applications, bases de données, configurations et certificats SSL vers un nouveau serveur via un seul serveur chiffré AES-256 transfert. La reprise après sinistre cesse d’être un projet et devient une commande.

Installation en une seule commande

Un seul script transforme un nouveau Ubuntu VPS en une pile de production complète : Nginx, PHP 8.5, MariaDB ou PostgreSQL, Valkey, Supervisor, Déployeur, Certbot.

Renseignement et surveillance

Cipi Agent

Un composer requis dans votre application Laravel déverrouille webhook déploiements, contrôles de santé, MCP et anonymisation. Découverte automatiquement, aucune configuration.

Plongée profonde

Serveur MCP pour l'IA

Six outils permettent à Cursor, VS Code ou Claude de lire les journaux, d'interroger la base de données, d'exécuter artisan et de déployer — au-dessus de HTTPS, avec SQL destructeur bloqué.

Plongée profonde

Critère de santé

Un point de terminaison JSON signalant la version PHP, la base de données, le cache, la file d'attente et les éléments vitaux du disque. Branchez-le sur UptimeRobot, Pingdom ou vos propres moniteurs.

Plongée profonde

Alertes par e-mail

Configurez SMTP une fois et soyez averti des échecs de déploiement, des erreurs de sauvegarde, des intrusions SSH, etc. les élévations et les changements clés. Vous dormez, Cipi regarde.

Plongée profonde

Flux d'événements

Chaque événement de déploiement, d'interdiction, de connexion et de cycle de vie apparaît dans un seul journal en temps réel à l'adresse /var/log/cipi/events.log — la boîte noire de votre serveur.

Plongée profonde

Emplois, travailleurs et planificateur

Horizon ou des tâches de file d'attente simples sous Supervisor, et le planificateur Laravel connecté à cron — géré par application et redémarré à chaque déploiement.

Sauvegarde et restauration de base de données

La base de données compressée est sauvegardée et restaurée en une seule commande chacune. Programmez-les en cron et oubliez syntaxe mysqldump pour toujours.

Plongée profonde

S3 sauvegardes hors site

Sauvegardes complètes des applications (code, base de données, .env, stockage) expédiées vers AWS S3, DO Spaces, MinIO ou Retour de flamme. Avec taille automatique des anciens ensembles.

Plongée profonde

Synchronisation du serveur A → B

Clonez des applications, des bases de données, des configurations et des certificats SSL sur un serveur de réplique via un AES-256 transfert SSH crypté. La migration rendue ennuyeuse.

Plongée profonde

Anonymiseur RGPD

Les règles d'anonymisation par table et par colonne produisent des vidages complets de la base de données avec le remplacement de fausses données. PI. Une vraie structure, zéro donnée personnelle.

Chaque identifiant créé par Cipi (mots de passe de base de données, jetons, secrets racine) est chiffré au repos dans un coffre-fort local. Rien ne reste en texte brut.
