Dokku alternative

Le Laravel-natif Dokku alternative

Dernière mise à jour de la comparaison : 4 août 2026 · reflète les prix/fonctionnalités actuels de Cipi 5 et de Dokku

Dokku et Cipi sont tous deux gratuits et open source (MIT). Dokku est un self-hosted Heroku — git push pour déployer des conteneurs Docker avec un riche écosystème de plugins. Cipi est Laravel-first, exécute des applications sur une pile native LEMP et ajoute une gestion complète du serveur CLI, un déployeur, un double MCP, un chiffrement au repos et une synchronisation du serveur.

Pourquoi les équipes Laravel choisissent Cipi plutôt que Dokku

Conçu pour Laravel

Le déployeur, les raccourcis artisan, les gestionnaires de file d'attente automatiques et les déploiements Git sans temps d'arrêt sont intégrés — Dokku traite PHP comme l'un des nombreux buildpacks conteneurisés.

Natif LEMP, non Docker

Exécutez PHP-FPM directement sur l'hôte pour réduire l'utilisation de la mémoire, un débogage plus simple et aucune couche de conteneur à gérer.

Gestion complète du serveur CLI

Provisionnez les serveurs, gérez SSL, les bases de données et le cycle de vie complet des applications, et pas seulement les déploiements git push de style PaaS.

Webhook déploiements sans temps d'arrêt

Déclencheurs atomiques à une commande pour GitHub et GitLab — conçus pour Laravel, non boulonnés.

IA native avec double MCP

Serveurs MCP par application et globaux pour une gestion complète de l'infrastructure basée sur l'IA à partir de n'importe quel agent compatible MCP.

Chiffrement au repos et synchronisation du serveur

AES-256-CBC Cryptage Vault pour toutes les configurations, ainsi qu'une synchronisation cryptée de serveur à serveur intégrée pour la réplication par basculement.

Laravel Octane (FrankenPHP)

Créez ou convertissez des applications avec cipi app create --octane / cipi app convert --to=octane. Exécutez Octane à côté des applications FPM classiques, ainsi que Horizon et Reverb de première classe — aucun panneau SaaS requis.

Facultatif PostgreSQL

MariaDB par défaut ; installez PostgreSQL avec une seule commande et choisissez un moteur par application (cipi db install pgsql).

Installez Cipi en une seule commande

Lancez un nouveau Ubuntu VPS, puis exécutez :

wget -O - https://cipi.sh/setup.sh | coup

Cela installe et configure la pile de production complète : Nginx, PHP-FPM / Laravel Octane, MariaDB, en option PostgreSQL, Redis et Supervisor. Voir le guide de démarrage.

Où Dokku est le meilleur choix

Dokku est un excellent PaaS self-hosted si vous souhaitez la simplicité de Git Push, un riche écosystème de plugins, des flux de travail de conteneurs et une courbe d'apprentissage minimale pour les réfugiés Heroku. Si votre flux de travail est git push-first et que vous privilégiez l'isolation des conteneurs par rapport à l'automatisation spécifique à Laravel ou à une pile PHP native, Dokku vaut la peine d'être évalué.

Comment migrer de Dokku vers Cipi

Passer de Dokku à Cipi est un basculement net plutôt qu'une conversion sur place : vous êtes debout nouveau serveur à côté de votre configuration actuelle, déployez à partir du même référentiel Git et changez DNS lorsque tout se vérifie. Votre base de code Laravel n'a pas besoin d'être modifiée.

  1. Faites l'inventaire de vos applications Dokku. Répertoriez vos applications avec dokku apps : répertoriez et exportez les bases de données à partir des plugins Postgres ou MySQL que vous utilisez.
  2. Provisionnez un nouveau Ubuntu VPS et installez Cipi. N'importe quel fournisseur fonctionne (Hetzner, DigitalOcean, Vultr, Linode, AWS). Sur Ubuntu 24.04/26.04 wget -O - https://cipi.sh/setup.sh | bash et la pile de production complète — Nginx, PHP, MariaDB, Valkey, Supervisor — est configurée en quelques minutes.
  3. Recréez chaque application et connectez Git. cipi app create provisionne une application isolée avec son propre utilisateur système, sa propre base de données, son pool PHP et son hôte virtuel Nginx (ajouter --octane pour Laravel Octane). La connexion de GitHub ou GitLab configure automatiquement les clés de déploiement et les webhooks pour des déploiements sans temps d'arrêt.
  4. Déplacez les données et effectuez une transition. Importez votre dump de base de données, copiez votre .env valeurs, émettez des certificats HTTPS avec cipi ssl install, puis pointez DNS vers le nouveau serveur et retirez l'ancienne configuration.

Cipi utilise les conventions standards Nginx, PHP-FPM / Laravel Octane et Deployer, il n'y a donc pas de configuration spécifique au fournisseur pour un déroulement ultérieur. Tous les détails dans le guide de démarrage.

Questions fréquemment posées

Cipi est-il une bonne alternative à Dokku pour Laravel ?

Oui. Les deux sont gratuits et open source. Dokku est un PaaS de style self-hosted Heroku avec des déploiements git push Docker ; Cipi est Laravel-first, exécute des applications sur une pile native LEMP avec Deployer, artisan, des files d'attente, un double MCP, un chiffrement au repos et une gestion complète du serveur CLI.

Quelle est la différence entre Cipi et Dokku ?

Dokku déploie des applications en tant que conteneurs Docker via git push avec un écosystème de plugins – idéal pour les flux de travail de style Heroku. Cipi installe et gère une pile LEMP traditionnelle directement sur Ubuntu, est exploité à partir de CLI et est spécialement conçu pour Laravel avec l'intégration de Deployer, les gestionnaires de file d'attente automatiques, le cryptage de configuration AES-256 et la synchronisation du serveur.

Est-ce que Cipi utilise Docker comme Dokku ?

Non, Dokku est axé sur le conteneur d'abord : chaque application s'exécute dans Docker via git push. Cipi utilise une pile native Nginx, PHP-FPM, MariaDB (PostgreSQL en option) et Supervisor sur le système d'exploitation hôte. Pour les applications Laravel standard, cela signifie une surcharge réduite, un débogage plus simple et aucune couche de conteneur à gérer.

Quand dois-je encore choisir Dokku ?

Choisissez Dokku si vous souhaitez la simplicité de git push, un écosystème de plugins riche, des flux de travail de conteneurs et une courbe d'apprentissage minimale pour les réfugiés Heroku - et vous n'avez pas besoin d'une automatisation spécifique à Laravel, d'une pile PHP native ou d'une gestion complète du serveur au-delà des déploiements PaaS.

Puis-je migrer de Dokku vers Cipi ?

Oui. Fournissez un nouveau Ubuntu VPS, installez Cipi avec une seule commande, recréez chaque application avec cipi app create, connectez votre référentiel GitHub ou GitLab pour des déploiements sans temps d'arrêt, importez votre vidage de base de données, puis pointez DNS sur le nouveau serveur. Aucun buildpack ou Dockerfile n'est nécessaire.

Cipi prend-il en charge le déploiement push-to-deploy comme Dokku ?

Oui, via les webhooks Git : connectez GitHub ou GitLab une fois et chaque poussée vers votre branche de production déclenche un déploiement sans temps d'arrêt - le même flux de travail, sans buildpacks ni conteneurs impliqués.
