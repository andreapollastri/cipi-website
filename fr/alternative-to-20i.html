L’alternative self-hosted à 20i pour Laravel

Dernière mise à jour de la comparaison : 7 septembre 2026 · reflète Cipi 5 et les produits actuels de 20i

20i est une société d’hébergement complète — offres revendeur, cloud géré, WordPress, VPS, domaines et le panneau My20i, avec plus de 60 centres de données et un support 24×7. Cipi n’est pas une société d’hébergement : vous apportez n’importe quel VPS Ubuntu, obtenez un CLI de déploiement Laravel-first, un root complet et une facture fixe. Gratuit, open source, et conçu pour les développeurs qui possèdent déjà le serveur.

Pourquoi les équipes choisissent Cipi plutôt que 20i

Un outil de déploiement, pas un contrat d’hébergement

Cipi est un logiciel libre sur un VPS que vous payez déjà. 20i est un hébergeur — produits revendeur, cloud, WordPress et VPS facturés via leur plateforme.

Vous choisissez le fournisseur

Root complet chez Hetzner, OVH, DigitalOcean, AWS ou bare metal. 20i héberge sur 20iCloud, AWS ou Google Cloud sous leur panneau.

Laravel-first, pas de l’hébergement générique

Octane, Horizon, Reverb, Deployer, artisan et les workers de file d’attente sont intégrés. 20i optimise pour les agences, WordPress, Magento/WooCommerce et les workflows revendeur.

CLI, API et double MCP

Tout est scriptable via SSH. 20i est d’abord un panneau (My20i / StackCP) avec Git — pas un CLI Laravel natif IA, orienté pipelines.

Open source et sans verrouillage de panneau

Sous licence MIT et auditable. Quitter 20i, c’est quitter leur panneau, CDN et outillage revendeur ; quitter Cipi laisse une boîte LEMP standard.

Chiffrement au repos + souveraineté

Toutes les configurations chiffrées avec AES-256-CBC sur un VPS dans la région que vous choisissez : aucune donnée d’infrastructure ne quitte votre machine.

Laravel Octane (FrankenPHP)

Créez ou convertissez des applications avec cipi app create --octane / cipi app convert --to=octane. Exécutez Octane à côté des applications FPM classiques sur le même serveur.

PostgreSQL en option

MariaDB par défaut ; installez PostgreSQL avec une seule commande et choisissez un moteur par application (cipi db install pgsql).

Installez Cipi en une seule commande

Lancez un nouveau VPS Ubuntu, puis exécutez :

wget -O - https://cipi.sh/setup.sh | bash

Cela installe et configure la pile de production complète : Nginx, PHP-FPM / Laravel Octane, MariaDB, PostgreSQL en option, Redis et Supervisor. Voir le guide de démarrage.

Où 20i est le meilleur choix

20i gagne en tant que société d’hébergement : support humain 24×7, CDN gratuit, migrations en un clic, plus de 60 centres de données, marque revendeur/StackCP, domaines, e-mail, WordPress Manager, Agency Hub et revendications d’énergie verte. Si vous vendez de l’hébergement, avez besoin de WordPress à grande échelle, ou voulez un seul fournisseur pour sites, mail et DNS, 20i est le meilleur choix. Cipi s’adresse aux développeurs qui ont déjà un VPS et veulent des déploiements Laravel sans panneau d’hébergement.

Comment migrer de 20i vers Cipi

Passer de 20i à Cipi est un basculement net : vous installez un nouveau VPS Ubuntu, déployez depuis le même dépôt Git, importez les données et changez le DNS lorsque tout est vérifié. Votre base de code Laravel n’a pas besoin d’être modifiée.

  1. Exportez vos données depuis 20i. Utilisez leur Migration Center ou prenez un dump de base et une copie des fichiers depuis My20i. Notez la version PHP, le cron, le mail et le DNS afin de recréer ce que Cipi doit posséder vs ce que vous gardez ailleurs.
  2. Provisionnez un nouveau VPS Ubuntu et installez Cipi. N’importe quel fournisseur fonctionne (Hetzner, DigitalOcean, Vultr, Linode, AWS). Sur Ubuntu 24.04/26.04, exécutez wget -O - https://cipi.sh/setup.sh | bash et la pile de production complète — Nginx, PHP, MariaDB, Valkey, Supervisor — est configurée en quelques minutes.
  3. Recréez chaque application et connectez Git. cipi app create provisionne une application isolée avec son propre utilisateur système, sa base de données, son pool PHP et son hôte virtuel Nginx (ajoutez --octane pour Laravel Octane). La connexion de GitHub ou GitLab configure automatiquement les clés de déploiement et les webhooks pour des déploiements sans temps d’arrêt.
  4. Déplacez les données et basculez. Importez votre dump de base de données, copiez vos valeurs .env, émettez des certificats HTTPS avec cipi ssl install, puis pointez le DNS vers le nouveau serveur et retirez l’ancienne configuration.

Cipi utilise les conventions standards Nginx, PHP-FPM / Laravel Octane et Deployer, il n'y a donc pas de configuration spécifique au fournisseur à démêler plus tard. Tous les détails dans le guide de démarrage.

Questions fréquemment posées

Cipi est-il une alternative à 20i ?

Pour l’hébergement d’applications Laravel, oui. Cipi est un CLI de déploiement gratuit et open-source que vous installez sur votre propre VPS Ubuntu. 20i est une société d’hébergement avec des produits revendeur, WordPress, cloud et VPS — une autre catégorie si vous avez besoin de domaines, d’e-mail ou d’hébergement en marque blanche.

Quelle est la différence entre Cipi et 20i ?

20i vend de l’hébergement géré via My20i, avec CDN, migrations et support 24×7. Cipi ne vend pas d’hébergement : il provisionne une pile de production Laravel sur un VPS que vous possédez déjà, avec CLI, API REST, double MCP et chiffrement de configuration AES-256.

Cipi est-il moins cher que 20i ?

Cipi lui-même est gratuit ; vous ne payez que le VPS. Les prix 20i dépendent du produit (revendeur, cloud géré dès environ 10,99 $/mois, WordPress, VPS). Comparez le VPS plus Cipi à l’offre 20i qui correspond à vos sites.

Quand dois-je encore choisir 20i ?

Choisissez 20i si vous voulez un hébergeur avec support 24×7, marque revendeur, outillage WordPress, domaines, e-mail et un CDN mondial — pas un CLI Laravel à faire soi-même sur un VPS brut.

Puis-je migrer de 20i vers Cipi ?

Oui pour les applications Laravel (et autres PHP). Provisionnez un VPS Ubuntu, installez Cipi, recréez chaque site, importez la base et les fichiers, puis pointez le DNS. Gardez 20i pour le mail ou les domaines si vous en avez encore besoin.

Cipi inclut-il un panneau de contrôle comme My20i ?

En option. L’exécution de cipi gui votredomaine.com installe un panneau web gratuit et self-hosted. Contrairement à My20i, il est opt-in et s’exécute sur votre infrastructure ; Cipi reste entièrement utilisable depuis le CLI seul.
