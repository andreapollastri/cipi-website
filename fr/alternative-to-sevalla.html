L’alternative self-hosted à Sevalla

Comparaison mise à jour le 7 septembre 2026 · reflète Cipi 5 et les tarifs/fonctionnalités actuels de Sevalla

Sevalla est la plateforme d’applications de Kinsta — apps, bases de données, stockage objet et sites statiques, MCP pour les agents, paiement à l’usage, 25 centres de données. Cipi est l’opposé : vous possédez un VPS chez n’importe quel fournisseur, avec un accès root complet, un coût fixe prévisible et un outillage Laravel-first — tout en déployant en quelques minutes. Gratuit, open source et entièrement piloté par CLI.

Pourquoi les équipes choisissent Cipi plutôt que Sevalla

Coût prévisible et fixe

Cipi est gratuit ; vous ne payez que le VPS. Sevalla n’a pas de forfaits — vous payez le calcul, les bases, le stockage et l’équilibrage de charge selon la consommation.

Vous êtes propriétaire du serveur

Root complet chez n’importe quel fournisseur. Sevalla abstrait les clusters ; vous n’obtenez jamais la machine.

Aucun vendor lock-in

Cipi utilise une stack standard et portable Ubuntu + Nginx + PHP-FPM / Laravel Octane + MariaDB (PostgreSQL en option) + Supervisor que vous pouvez reproduire n’importe où.

Laravel-first, pas un kit cloud DIY

Octane, Horizon, Reverb, Deployer et les files d’attente sont intégrés. Sevalla exécute ce que vous livrez (Git ou Docker) sans outillage de cycle de vie Laravel.

Open source et IA native

Sous licence MIT et auditable, avec un double serveur MCP. Sevalla expose aussi un MCP pour les agents — sur leur plan de contrôle hébergé.

Chiffrement au repos + souveraineté

Toutes les configurations chiffrées avec AES-256-CBC sur un VPS dans la région que vous choisissez : aucune donnée d’infrastructure ne quitte votre machine.

Laravel Octane (FrankenPHP)

Créez ou convertissez vos applications avec cipi app create --octane / cipi app convert --to=octane sans câbler une image de conteneur.

PostgreSQL en option

MariaDB par défaut ; installez PostgreSQL en une commande et choisissez le moteur application par application (cipi db install pgsql) — sans SKU de base séparé.

Installer Cipi en une seule commande

Lancez un VPS Ubuntu neuf, puis exécutez :

wget -O - https://cipi.sh/setup.sh | bash

Cela installe et configure la stack de production complète : Nginx, PHP-FPM / Laravel Octane, MariaDB, PostgreSQL en option, Redis et Supervisor. Voir le guide de démarrage.

Où Sevalla est le meilleur choix

Sevalla gagne sur un cloud de production groupé : hébergement d’applications, bases gérées, stockage objet compatible S3 et sites statiques qui fonctionnent ensemble, plus MCP pour les agents de déploiement et de debug, 25 régions, un réseau edge, et la conformité portée par Kinsta (SOC 2, ISO 27001, RGPD). Si vous voulez abandonner un stack AWS/Kubernetes maison et ne jamais toucher un VPS, Sevalla est le meilleur choix. Cipi s’adresse aux équipes Laravel qui veulent posséder la machine et automatiser depuis le CLI.

Comment migrer de Sevalla vers Cipi

Passer de Sevalla à Cipi est un basculement net plutôt qu’une conversion sur place : vous installez un nouveau serveur à côté de votre configuration actuelle, déployez depuis le même dépôt Git et changez le DNS lorsque tout est vérifié. Votre base de code Laravel n’a pas besoin d’être modifiée.

  1. Exportez vos données depuis Sevalla. Videz la base gérée, copiez les assets de stockage objet dont vous avez encore besoin sur disque, et notez les variables d’environnement, les commandes de build/start et les réglages de scaling.
  2. Provisionnez un VPS Ubuntu neuf et installez Cipi. N’importe quel fournisseur convient (Hetzner, DigitalOcean, Vultr, Linode, AWS). Sur Ubuntu 24.04/26.04, lancez wget -O - https://cipi.sh/setup.sh | bash et la stack de production complète — Nginx, PHP, MariaDB, Valkey, Supervisor — est configurée en quelques minutes.
  3. Recréez chaque application et branchez Git. cipi app create provisionne une application isolée avec son propre utilisateur système, sa base de données, son pool PHP et son vhost Nginx (ajoutez --octane pour Laravel Octane). La connexion de GitHub ou GitLab configure automatiquement les clés de déploiement et les webhooks pour des déploiements sans interruption.
  4. Migrez les données et basculez. Importez votre dump de base de données, reprenez vos valeurs .env, émettez des certificats HTTPS avec cipi ssl install, puis faites pointer le DNS vers le nouveau serveur et mettez l’ancienne installation hors service.

Cipi s’appuie sur les conventions standard de Nginx, PHP-FPM / Laravel Octane et Deployer : aucune configuration propre à un fournisseur ne restera à défaire plus tard. Tous les détails dans le guide de démarrage.

Questions fréquentes

Existe-t-il une alternative self-hosted à Sevalla ?

Oui. Cipi est une alternative gratuite, open-source (MIT) et self-hosted à Sevalla pour Laravel. Au lieu de la plateforme d’applications Kinsta facturée à l’usage, vous possédez un VPS chez n’importe quel fournisseur et Cipi y installe et gère la stack de production complète.

Quelle est la différence entre Cipi et Sevalla ?

Sevalla est une plateforme gérée pour apps, bases de données, stockage objet et sites statiques, avec MCP et facturation à la ressource. Cipi s’exécute sur votre propre VPS avec un accès root complet et un coût fixe, est open source, et est Laravel-first avec Octane, un double serveur MCP et le chiffrement de configuration au repos.

Cipi est-il moins cher que Sevalla ?

Cipi lui-même est gratuit ; votre seul coût est le VPS. Sevalla facture le calcul, les bases, le stockage et l’équilibrage de charge à l’usage — souvent plus simple qu’AWS, mais toujours une facture cloud variable.

Quand dois-je encore choisir Sevalla ?

Choisissez Sevalla si vous voulez zéro travail d’infrastructure, des bases et un stockage objet groupés, des régions mondiales et l’accès agents via leur MCP — et si vous acceptez de payer des ressources plutôt qu’un VPS.

Puis-je migrer de Sevalla vers Cipi ?

Oui. Provisionnez un VPS Ubuntu, installez Cipi, créez l’application avec cipi app create (ajoutez --octane pour continuer à exécuter Octane), restaurez votre base, copiez les valeurs d’environnement et pointez le DNS. Le stockage objet peut rester compatible S3 hors boîte.

Cipi prend-il en charge Laravel Octane ?

Oui. Cipi fait tourner Laravel Octane sur FrankenPHP nativement : créez des applications Octane avec cipi app create --octane ou convertissez des applications existantes avec cipi app convert --to=octane, aux côtés des applications PHP-FPM classiques sur le même serveur.
