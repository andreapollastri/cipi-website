Alternative à Laravel Cloud

Le self-hosted Alternative à Laravel Cloud

Comparaison mise à jour le 4 août 2026 · reflète les tarifs/fonctionnalités actuels de Cipi 5 et de Laravel Cloud

Laravel Cloud supprime le serveur avec un PaaS basé sur l'utilisation sur AWS. Cipi est le contraire : vous possédez un VPS chez n'importe quel fournisseur, avec un accès root complet, un coût fixe prévisible et sans dépendance envers un fournisseur - tout en je déploie toujours Laravel en quelques minutes. Gratuit, open source et entièrement piloté par CLI.

Pourquoi les équipes choisissent Cipi plutôt que Laravel Cloud

Coût prévisible et fixe

Cipi est gratuit ; vous ne payez que le VPS à un prix forfaitaire. Laravel Cloud facture une utilisation qui évolue avec le trafic et peut être difficile à prévoir.

Vous êtes propriétaire du serveur

Root complet et SSH sur n'importe quel fournisseur : Hetzner, OVH, DigitalOcean, AWS ou bare metal. Le cloud ne vous donne jamais la machine sous-jacente.

Aucun vendor lock-in

Cipi utilise une stack standard et portable Ubuntu + Nginx + PHP-FPM / Laravel Octane + MariaDB (PostgreSQL en option) + Supervisor que vous pouvez reproduire n'importe où.

Aucune dépendance SaaS

Cipi vit sur votre VPS et continue de fonctionner indépendamment de tout plan de contrôle externe.

Open source et IA native

Sous licence MIT et auditable, avec un double serveur MCP pour une gestion complète de l'infrastructure basée sur l'IA.

Chiffrement au repos + souveraineté

Toutes les configurations chiffrées avec AES-256-CBC sur un VPS dans la région que vous choisissez : aucune donnée d'infrastructure ne quitte votre machine.

Laravel Octane (FrankenPHP)

Créez ou convertissez vos applications avec cipi app create --octane / cipi app convert --to=octane. Faites tourner Octane à côté des applications FPM classiques, avec Horizon et Reverb pris en charge nativement — sans aucun panneau SaaS.

Facultatif PostgreSQL

MariaDB par défaut ; installez PostgreSQL en une commande et choisissez le moteur application par application (cipi db install pgsql).

Installer Cipi en une seule commande

Lancez un VPS Ubuntu neuf, puis exécutez :

wget -O - https://cipi.sh/setup.sh | bash

Cela installe et configure toute la stack de production — Nginx, PHP-FPM / Laravel Octane, MariaDB, PostgreSQL en option, Redis et Supervisor. Voir le guide de démarrage.

Où Laravel Cloud est le meilleur choix

Laravel Le cloud gagne en matière de gestion de serveur zéro, de mise à l'échelle automatique en un clic et de mise à l'échelle jusqu'à zéro, bases de données gérées et cache, un réseau périphérique mondial avec protection DDoS, équilibrage de charge automatique et files d'attente gérées — le tout sans jamais toucher à un serveur. Si vous souhaitez une expérience de style serverless et que vous ne souhaitez pas posséder ou gérer un VPS, Cloud est la meilleure solution.

Comment migrer de Laravel Cloud vers Cipi

Passer de Laravel Cloud à Cipi est un basculement net plutôt qu'une conversion sur place : vous êtes debout nouveau serveur à côté de votre configuration actuelle, déployez à partir du même référentiel Git et changez DNS lorsque tout se vérifie. Votre base de code Laravel n'a pas besoin d'être modifiée.

  1. Exportez vos données depuis Laravel Cloud. Videz votre base de données de production et notez les variables d'environnement dont chaque application a besoin (files d'attente, cache, courrier, stockage) afin de pouvoir les recréer sur votre propre serveur.
  2. Provisionnez un VPS Ubuntu neuf et installez Cipi. N’importe quel fournisseur convient (Hetzner, DigitalOcean, Vultr, Linode, AWS). Sur Ubuntu 24.04/26.04, lancez wget -O - https://cipi.sh/setup.sh | bash et la stack de production complète — Nginx, PHP, MariaDB, Valkey, Supervisor — est configurée en quelques minutes.
  3. Recréez chaque application et branchez Git. cipi app create provisionne une application isolée avec son propre utilisateur système, sa base de données, son pool PHP et son vhost Nginx (ajoutez --octane pour Laravel Octane). La connexion de GitHub ou GitLab configure automatiquement les clés de déploiement et les webhooks pour des déploiements sans interruption.
  4. Migrez les données et basculez. Importez votre dump de base de données, reprenez vos .env valeurs, émettez des certificats HTTPS avec cipi ssl install, puis faites pointer le DNS vers le nouveau serveur et mettez l’ancienne installation hors service.

Cipi s’appuie sur les conventions standard de Nginx, PHP-FPM / Laravel Octane et Deployer : aucune configuration propre à un fournisseur ne restera à défaire plus tard. Tous les détails dans le guide de démarrage.

Questions fréquentes

Existe-t-il une alternative self-hosted au Laravel Cloud ?

Oui. Cipi est une alternative gratuite, open-source (MIT) et self-hosted à Laravel Cloud. Au lieu d'un PaaS géré basé sur l'utilisation, vous possédez un VPS chez n'importe quel fournisseur et Cipi y installe et gère la stack de production complète.

Quelle est la différence entre Cipi et Laravel Cloud ?

Laravel Cloud est un PaaS entièrement géré et basé sur l'utilisation sur AWS, où vous n'obtenez jamais d'accès root ou SSH. Cipi fonctionne seul VPS avec un accès root complet et un coût fixe et prévisible, est open source et offre l'automatisation CLI, un double serveur MCP et un chiffrement de configuration au repos.

Cipi est-il moins cher que Laravel Cloud ?

Cipi lui-même est gratuit ; votre seul coût est le VPS, à un prix mensuel fixe. Laravel Le cloud est basé sur l'utilisation : le calcul, les bases de données, le cache, la bande passante et le stockage sont facturés au fur et à mesure que vous les consommez. Les coûts évoluent donc avec le trafic et peuvent être plus difficiles à prévoir.

Quand dois-je encore choisir Laravel Cloud ?

Choisissez Laravel Cloud si vous souhaitez une gestion de serveur nulle, une mise à l'échelle automatique et une mise à l'échelle jusqu'à zéro en un clic, des bases de données et un cache gérés, un réseau périphérique mondial avec protection DDoS et que vous êtes à l'aise avec une facture basée sur l'utilisation.

Puis-je migrer de Laravel Cloud vers Cipi ?

Oui. Étant donné que votre application est standard Laravel, vous pouvez provisionner un VPS Ubuntu, installer Cipi, créer l'application avec cipi app create (ajouter --octane pour continuer à exécuter Octane), restaurer votre dump de base de données, copier les valeurs de votre environnement et pointer DNS. Vous échangez la facturation PaaS basée sur l'utilisation contre un coût VPS fixe et prévisible.

Cipi prend-il en charge Laravel Octane comme Laravel Cloud ?

Oui. Cipi fait tourner Laravel Octane sur FrankenPHP nativement : créez des applications Octane avec cipi app create --octane ou convertissez des applications existantes avec cipi app convert --to=octane, fonctionnant aux côtés des applications classiques PHP-FPM sur le même serveur.
