git push.
Ese es todo el proceso.

Conecte GitHub o GitLab una vez y Cipi se encarga del resto: implemente claves generadas e inyectadas, webhooks creada, cada aplicación se aprovisiona con su propio usuario de Linux, base de datos, vhost y grupo de PHP-FPM. Empuja a tu sucursal y una implementación sin tiempo de inactividad y verificada por firma se ejecuta en segundo plano, con un solo comando retroceder si alguna vez lo necesita. No hay CI/CD que mantener. No hay tubería YAML por la que llorar.

cipi.yml

Configuración que viaja con el código.

Haz commit de un archivo junto a la app: alias de dominio, versión PHP y php.ini, bases de datos extra, workers de cola o Horizon, Laravel Reverb, el scheduler, un healthcheck y perfiles de backup. Generalo desde el servidor, inspecciona el plan, aplícalo — o actívalo para que cada deploy exitoso se reconcilie. El esquema no lleva comandos shell; un archivo inválido se rechaza por completo, nunca a medias.

generate plan apply auto on deploy

Colas, websockets, cron.
Ya corriendo.

Horizon o trabajadores de cola simple se ejecutan en Supervisor y se reinician automáticamente en cada implementación. Laravel Reverb empuja los websockets en tiempo real a través de Nginx con SSL. El planificador está conectado a cron en el momento se crea la aplicación. Los trabajos en segundo plano, las transmisiones y las tareas programadas no son una idea de último momento: son parte del aprovisionamiento.

Nativo de IA

Tu IA tiene un línea directa a la producción.

El servidor MCP integrado conecta Cursor, VS Code o Claude Desktop directamente a su aplicación en vivo a través de HTTPS. Haga preguntas en lenguaje natural: lea registros, ejecute consultas SQL, ejecute artisan comandos, active se despliega. Las declaraciones destructivas se bloquean, nunca se abre ninguna sesión SSH y nunca se pega una pila rastrear en una ventana de chat nuevamente.

Autenticación solo con clave SSH, Fail2ban con prohibición progresiva, firewall UFW, seguridad desatendida actualizaciones, una bóveda AES-256 para cada credencial, retención de registros compatible con GDPR y soporte completo para usuarios de Linux. aislamiento por aplicación. Resiliencia

Perder un servidor te cuesta un comando.

Código, base de datos, .env y almacenamiento: cifrados y enviados a cualquier depósito compatible con S3 según lo programado. Restaure una base de datos con un comando, revierta una versión con otro. Y cuando llega el momento de migrar o recuperarse, cipi sync clones de aplicaciones, bases de datos, configuraciones y certificados SSL a un servidor nuevo a través de un único cifrado AES-256. transferencia. La recuperación ante desastres deja de ser un proyecto y se convierte en un comando.

Provisión y desempeño

Instalación con un solo comando

Un solo guión convierte un nuevo Ubuntu VPS en una pila de producción completa: Nginx, PHP 8,5, MariaDB o PostgreSQL, Valkey, Supervisor, Deployer, Certbot.

inmersión profunda

Octane en FrankenPHP

Sirve cada aplicación en Laravel Octane con tecnología FrankenPHP para velocidad bruta o en versión clásica PHP-FPM probado en batalla. Una bandera por aplicación, tú decides.

inmersión profunda

MariaDB o PostgreSQL

MariaDB de forma predeterminada, PostgreSQL a un comando de distancia. Elija el motor por aplicación: .env y conexión Las URL se siguen automáticamente.

inmersión profunda

Valkey caché y colas

Un almacén en memoria compatible con Redis para caché, sesiones y colas: instalado, protegido y conectado a todas las aplicaciones listas para usar.

inmersión profunda

Horizon y Reverb

Laravel Horizon vigilando sus colas y Reverb websockets detrás de Nginx con SSL – aprovisionados y supervisado para usted.

inmersión profunda

Aplicaciones completamente aisladas

Cada aplicación tiene su propio usuario de Linux, base de datos, Nginx vhost, grupo de PHP-FPM y trabajadores. uno La aplicación comprometida nunca toca a otra.

inmersión profunda

Implementaciones sin tiempo de inactividad

Lanzamientos atómicos basados ​​en implementadores con conmutación de enlaces simbólicos y reversión con un solo comando. Tus usuarios nunca ver una página de mantenimiento.

inmersión profunda

git push auto-deploy

Los webhooks verificados por la firma HMAC activan implementaciones en segundo plano en cada inserción. Filtrado de ramas incluido, no se requiere tubería CI/CD.

inmersión profunda

cipi.yml

Configuración que se envía con el código: alias, PHP, bases de datos, trabajadores, Reverb, planificador, Comprobación de estado y copias de seguridad: planificadas, aplicadas o conciliadas en cada implementación.

inmersión profunda

Automático SSL

Let's Encrypt certificados instalados y renovados automáticamente: se admiten dominios comodín. HTTPS es un comando, luego es para siempre.

No sólo Laravel

Aprovisionamiento de aplicaciones personalizadas Nginx + PHP-FPM con una raíz htdocs clásica: perfecta para sitios estáticos. SPA, WordPress, Symfony o simple PHP. Listo para SFTP.

GitHub y GitLab nativo

DESCANSO API

Cada comando CLI es también un punto final HTTP. Autenticación de token con capacidades detalladas, JSON respuestas y trabajos asíncronos con sondeo de estado.

inmersión profunda

Ir CLI cliente

El binario cipi-cli administra aplicaciones, SSL, implementaciones y bases de datos desde su computadora portátil, con perfiles multiservidor y una descripción general del estado global.

inmersión profunda

Web multiservidor GUI

¿Prefieres hacer clic que escribir? Un panel opcional con 2FA controla todos sus servidores desde un solo Tablero: una cabina liviana con múltiples servidores encima del mismo API.

inmersión profunda

Módulo de facturación WHMCS

Vender hosting por encima de Cipi. Los pedidos de los clientes en WHMCS, el módulo aprovisiona, suspende y finaliza las aplicaciones a través de API automáticamente.

Inteligencia y Monitoreo

Cipi Agente

Un requisito composer dentro de su aplicación Laravel desbloquea implementaciones webhook, comprobaciones de estado, MCP y anonimización. Descubrimiento automático, configuración cero.

inmersión profunda

MCP servidor para IA

Seis herramientas permiten a Cursor, VS Code o Claude leer registros, consultar la base de datos, ejecutar artisan e implementar — más de HTTPS, con SQL destructivo bloqueado.

inmersión profunda

Punto final de salud

Un punto final JSON que informa PHP versión, base de datos, caché, cola y datos vitales del disco. Conéctalo a UptimeRobot, Pingdom o tus propios monitores.

inmersión profunda

Alertas por correo electrónico

Configure SMTP una vez y reciba notificaciones sobre fallas de implementación, errores de respaldo, intrusiones SSH, sudo elevaciones y cambios clave. Tú duermes, Cipi mira.

inmersión profunda

Feed de eventos

Cada evento de implementación, prohibición, inicio de sesión y ciclo de vida llega a un único registro en tiempo real en /var/log/cipi/events.log: la caja negra de su servidor.

inmersión profunda

Empleos, trabajadores y programador

Horizon o trabajadores en cola simple bajo Supervisor, y el programador Laravel conectado a cron — administrado por aplicación y reiniciado en cada implementación.

inmersión profunda

Datos y defensa

Copia de seguridad y restauración de base de datos

La base de datos comprimida se vuelca y restaura con un comando cada uno. Agendalas en cron y olvídate sintaxis de mysqldump para siempre.

inmersión profunda

S3 copias de seguridad externas

Copias de seguridad completas de aplicaciones (código, base de datos, .env, almacenamiento) enviadas a AWS S3, DO Spaces, MinIO o Contrafuego. Con poda automática de conjuntos antiguos.

inmersión profunda

Sincronización del servidor A→B

Clonar aplicaciones, bases de datos, configuraciones y certificados SSL en un servidor de réplica a través de un AES-256 transferencia SSH cifrada. La migración se volvió aburrida.

inmersión profunda

Anonimizador RGPD

Las reglas de anonimización por tabla y por columna producen volcados completos de bases de datos con reemplazo de datos falsos PII. Estructura real, cero datos personales.

inmersión profunda

AES-256 bóveda

Cada credencial que crea Cipi (contraseñas de bases de datos, tokens, secretos de raíz) está cifrada en reposo. en una bóveda local. Nada se encuentra en texto plano.

inmersión profunda
