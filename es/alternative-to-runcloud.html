RunCloud es un panel de control PHP, pero no es nativo de Laravel; implementar Laravel significa cablear Implementador, colas y artisan a mano. Cipi entiende Laravel listo para usar: implementador automático integración, trabajadores en cola, lanzamientos sin tiempo de inactividad: gratis, open source y totalmente CLI impulsado por su cuenta Ubuntu VPS.

Por qué los desarrolladores Laravel cambian de RunCloud a Cipi

Laravel-nativo, configuración cero

Cipi configura automáticamente el implementador, artisan accesos directos, Supervisor trabajadores de cola y la estructura de directorio compartido. RunCloud necesita cableado manual.

$0 instead of $12–18/mo

RunCloud facturas por servidor cada mes. Cipi es gratuito para todos tus servidores, para siempre.

Verdaderos lanzamientos sin tiempo de inactividad

Lanzamientos atómicos impulsados por Webhook para GitHub y GitLab en un solo comando, no scripts de implementación escritos a mano.

Sin dependencia de SaaS

Cipi se ejecuta completamente en tu VPS; RunCloud gestiona servidores desde su propio panel en la nube.

Nativo de IA con doble MCP

Administre aplicaciones, implementaciones y SSL en todo el servidor desde cualquier IDE o agente compatible con MCP.

Open source y cifrado en reposo

Con licencia MIT y auditable, con todas las configuraciones cifradas usando AES-256-CBC en su servidor.

Laravel Octane (FrankenPHP)

Crea o convierte aplicaciones con cipi app create --octane / cipi app convert --to=octane. Ejecute Octane junto a las aplicaciones FPM clásicas, además de Horizon y Reverb de primera clase; no se requiere panel SaaS.

Opcional PostgreSQL

MariaDB por defecto; instale PostgreSQL con un comando y elija un motor por aplicación (cipi db install pgsql).

Instale Cipi en un solo comando

Ejecute un Ubuntu VPS nuevo y luego ejecute:

wget -O - https://cipi.sh/setup.sh | fiesta

Eso instala y configura la pila de producción completa: Nginx, PHP-FPM / Laravel Octane, MariaDB, opcional PostgreSQL, Redis y Supervisor. Ver el guía de introducción.

Donde RunCloud sigue siendo la mejor opción

RunCloud es compatible con Nginx y Apache y es popular para WordPress y alojamiento genérico PHP con un panel visual amigable. Si su carga de trabajo es principalmente WordPress o no es Laravel PHP y prefiere GUI, RunCloud es una opción razonable.

Cómo migrar de RunCloud a Cipi

Pasar de RunCloud a Cipi es una transición limpia en lugar de una conversión in situ: se levanta un servidor nuevo junto a su configuración actual, implemente desde el mismo repositorio de Git y cambie DNS cuando todo está comprobado. No es necesario cambiar su base de código Laravel.

  1. Realice un inventario en el panel RunCloud. Enumere sus aplicaciones web, cron trabajos, supervisor trabajos y bases de datos para que pueda recrearlos en el nuevo servidor.
  2. Aprovisione un Ubuntu VPS nuevo e instale Cipi. Cualquier proveedor funciona (Hetzner, DigitalOcean, Vultr, Linode, AWS). El Ubuntu 24.04/26.04 ejecutar wget -O - https://cipi.sh/setup.sh | bash y la pila de producción completa (Nginx, PHP, MariaDB, Valkey, Supervisor) se configura en minutos.
  3. Recrea cada aplicación y conecta Git. cipi app create aprovisiona una aplicación aislada con su propio usuario del sistema, base de datos, grupo PHP y Nginx vhost (agregue --octane para Laravel Octane). La conexión de GitHub o GitLab configura las claves de implementación y los webhooks automáticamente para implementaciones sin tiempo de inactividad.
  4. Mueve datos y corta. Importe el volcado de su base de datos, copie su .env valores, emita HTTPS certificados con cipi ssl install, luego apunte DNS al nuevo servidor y retire la configuración anterior.

Cipi usa las convenciones estándar Nginx, PHP-FPM / Laravel Octane y del implementador, por lo que no hay configuración específica del proveedor para deshacerla más tarde. Detalles completos en el guía de introducción.

Preguntas frecuentes

¿Existe una alternativa gratuita a RunCloud?

Sí. Cipi es una alternativa gratuita, open-source (MIT) y self-hosted a RunCloud. Instala y administra una pila de producción completa en cualquier Ubuntu VPS sin suscripción mensual ni tarifa por servidor.

¿Cuál es la diferencia entre Cipi y RunCloud?

RunCloud es un panel de control SaaS orientado a PHP ($12–18/mes por servidor) que no es nativo de Laravel: sin implementador integrado, sin accesos directos artisan y sin configuración automática Supervisor para colas Laravel. Cipi es nativo de Laravel y maneja todo esto automáticamente, de forma gratuita, desde CLI.

¿Es Cipi mejor que RunCloud para Laravel?

Para Laravel específicamente, Cipi le ofrece mucho más listo para usar (integración automática del implementador, comandos artisan, trabajadores en cola y liberaciones sin tiempo de inactividad) sin costo alguno. RunCloud requiere la configuración manual de las piezas que Cipi maneja automáticamente.

¿Cuándo debería seguir eligiendo RunCloud?

Elija RunCloud si aloja principalmente aplicaciones WordPress o PHP genéricas, necesita soporte de Apache junto con Nginx y prefiere un panel web visual en lugar de un flujo de trabajo de CLI.

¿Puedo migrar de RunCloud a Cipi?

Sí. Proporcione un Ubuntu VPS nuevo, instale Cipi con un comando, vuelva a crear cada aplicación con cipi creación de aplicaciones, conecte su repositorio GitHub o GitLab para implementaciones sin tiempo de inactividad, importe el volcado de su base de datos y luego apunte DNS al nuevo servidor. Su base de código Laravel en sí no necesita cambios.

¿Cipi tiene un panel web como RunCloud?

Sí, opcionalmente. Al ejecutar cipi gui tudominio.com se instala un panel de control web self-hosted gratuito que administra uno o más Cipi servidores desde el navegador: aplicaciones, bases de datos, SSL, implementaciones y registros. A diferencia de RunCloud, el panel es opcional y se ejecuta en su propia infraestructura; Cipi sigue siendo totalmente utilizable solo desde CLI.
