Desplegar Laravel, sin fricción.

CLI open source pensada para Laravel, con IA y MCP — y también para sitios estáticos y PHP genérico. Un comando instala el stack. Un comando crea una app aislada con base de datos, workers, SSL y despliegues sin downtime.

Empezar Descubrimiento
cipi · configuración
# Fresh Ubuntu 24.04 or 26.04 VPS
$ wget -O - https://cipi.sh/setup.sh | bash

# Create an app
$ cipi app create myapp --domain=myapp.com --php=8.5

OK  Nginx · PHP-FPM / Octane · MariaDB · SSL · Deployer

Opcional

Una API REST cómoda,
cuando la necesites.

Cipi sigue siendo CLI-first por defecto, pero en cuanto quieras automatizar, integrar o dejar que los agentes de IA gestionen tus servidores, activa la capa API opcional con un solo comando. Usa la REST API para crear y gestionar varias aplicaciones en toda tu infraestructura desde un único endpoint. El Cliente CLI (cipi-cli) lleva toda la API a tu terminal local: gestiona apps, bases de datos, SSL y despliegues sin SSH. Un servidor MCP global te permite crear y gestionar tu infraestructura a través de tus agentes de IA, y un módulo de provisioning de WHMCS oficial crea y cancela apps automáticamente desde tu panel de facturación.

Integración de facturación

Vende hosting con
WHMCS, con Cipi por debajo.

Convierte tu servidor Cipi en un negocio de hosting. El módulo oficial de provisioning para WHMCS conecta tu panel de facturación con la API REST de Cipi: cuando un cliente contrata un producto, la app se crea automáticamente. Cancelar, suspender, reactivar: todo va de WHMCS a tu servidor sin una sola sesión SSH.

  • Provisioning totalmente automático: el cliente contrata y la app se pone en marcha
  • Tipos de app Laravel y personalizados, con versión de PHP y ajustes de Git por producto
  • Gestión asíncrona de jobs con sondeo de estado: sin timeouts HTTP
  • Autenticación con token Bearer y permisos granulares por ability
  • Test de conexión integrado: comprueba que la API responde desde el panel de administración de WHMCS
  • Open source con licencia MIT: amplíalo o ponlo en marca blanca como necesites

Gestión remota

Tu servidor,
desde cualquier terminal.

cipi-cli es un binario Go independiente que se comunica con la API REST de Cipi desde tu máquina local. Sin SSH: gestiona apps, bases de datos, certificados SSL y despliegues desde cualquier terminal. Disponible para Linux y macOS.

  • Ciclo de vida completo de la app: crear, editar, desplegar y eliminar desde tu máquina
  • Gestión de bases de datos: crear, hacer backup, restaurar y rotar contraseñas
  • Provisioning de SSL: instala certificados Let's Encrypt con un solo comando
  • Perfiles multiservidor: un perfil por servidor, se cambia con un prefijo
  • Vista global del estado: CPU, RAM, disco, apps y servicios de todos los servidores
  • Alias de dominio: añadir, listar y eliminar alias por app
  • Autocompletado de shell: instalación con un solo comando para zsh, bash y fish
  • Salida JSON: canalizable a jqpara scripts y pipelines de CI/CD
  • Open source con licencia MIT: binarios precompilados o compilación desde el código fuente

Panel web opcional

Una GUI, solo si
la quieres.

Cipi es CLI-first, y siempre lo será. Pero cuando el panel de un navegador encaja mejor, a ti o a tus clientes, un solo comando instala el panel de control web opcional: una app Laravel self-hosted que gestiona uno o varios servidores Cipi a través de la misma API REST. ¿No lo necesitas? No lo instales, nada cambia.

  • Un solo comando para instalarlo: cipi gui panel.example.com
  • Gestiona apps, SSL, logs y bases de datos desde el navegador
  • Un panel, muchos servidores: un cockpit multiservidor ligero
  • Login por sesión, con autenticación de dos factores TOTP opcional
  • Self-hosted y open source: tu panel, tu servidor, tus datos
  • Desinstálalo cuando quieras cipi gui remove — y vuelves a la CLI pura

Preguntas frecuentes

Las preguntas de siempre antes de instalar

¿Qué es Cipi?

Cipi es una CLI de despliegue open source pensada primero para Laravel, que también admite sitios estáticos y aplicaciones PHP genéricas. Un solo comando instala un stack de producción completo (Nginx, PHP-FPM o Laravel Octane, MariaDB, Valkey, Supervisor) en cualquier VPS Ubuntu.

¿Cipi es gratuito?

Sí. Cipi es 100 % gratuito y open source bajo licencia MIT. Lo alojas tú mismo en tu propio servidor, sin suscripción ni cuotas por servidor.

¿Cómo instalo Cipi?

Ejecuta un solo comando en un VPS Ubuntu recién creado: wget -O - https://cipi.sh/setup.sh | bash. Instala y configura automáticamente todo el stack de producción LEMP.

¿Es Cipi una alternativa a Laravel Forge?

Sí. Cipi es una alternativa gratuita, self-hosted y open source a Laravel Forge y a herramientas de despliegue similares: te da control total sobre tus servidores sin ningún coste recurrente. Consulta la comparación con Laravel Forge.

¿Qué servidores admite Cipi?

Cipi se ejecuta en cualquier VPS Ubuntu de proveedores como DigitalOcean, Hetzner, Vultr, Linode, AWS y más, convirtiendo un único servidor en una plataforma de alojamiento LEMP de múltiples aplicaciones.

¿Cipi admite Laravel Octane?

Sí. Cipi ejecuta Laravel Octane en FrankenPHP de forma nativa: crea Octane aplicaciones con cipi app create --octane o convertir aplicaciones existentes con cipi app convert --to=octane, ejecutándose junto con aplicaciones clásicas PHP-FPM en el mismo servidor.

¿Cipi tiene un panel de control web?

Sí, opcionalmente. Cipi es CLI-first, pero cipi gui yourdomain.com instala un panel web self-hosted gratuito que administra uno o más servidores Cipi desde el navegador: aplicaciones, bases de datos, SSL, despliegues y logs.

¿Pueden los agentes de IA administrar un servidor Cipi?

Sí. Cipi incluye un servidor dual MCP (Protocolo de contexto modelo), por lo que los IDE y agentes de IA compatibles con MCP pueden crear aplicaciones, ejecutar despliegues, administrar SSL y bases de datos a través de un API estructurado.
