moss.sh y Cipi administran PHP, Laravel y aplicaciones de Nodo en Ubuntu con implementaciones de Git, similar a Ploi. moss.sh es un administrador de sistemas virtual SaaS con GUI, flujos de trabajo de agencia y monitoreo de $9 a 49/mes (nivel gratuito: 25 implementaciones de git/mes). Cipi es gratuito, open source, self-hosted y CLI son los primeros con implementaciones ilimitadas, MCP dual, cifrado en reposo y sincronización de servidor.

Por qué Laravel equipos eligen Cipi en lugar de moss.sh

Sin cuota mensual

moss.sh factura entre $9 y $49 al mes, según el plan. Cipi es gratuito para todos los servidores, para siempre: sin niveles de plan ni actualizaciones.

Implementaciones ilimitadas

Los límites de niveles gratuitos de moss.sh se implementan en 25 por mes. Cipi nunca limita la frecuencia con la que implementas en todas tus aplicaciones y servidores.

Sin dependencia de SaaS

moss.sh controla tus servidores desde su panel SaaS. Cipi vive en su VPS y sigue funcionando incluso sin acceso al panel, y su propio panel web es opcional y self-hosted.

Open source y auditable

Con licencia MIT: lea, audite, bifurque y modifique. moss.sh es un SaaS de código cerrado.

Nativo de IA con doble MCP

Servidores MCP globales y por aplicación para una gestión completa de la infraestructura basada en IA desde cualquier agente compatible con MCP.

Cifrado en reposo y sincronización del servidor

AES-256-CBC Cifrado de bóveda para todas las configuraciones, además de sincronización cifrada integrada de servidor a servidor para replicación de conmutación por error.

Laravel Octane (FrankenPHP)

Crea o convierte aplicaciones con cipi app create --octane / cipi app convert --to=octane. Ejecute Octane junto a las aplicaciones FPM clásicas, además de Horizon y Reverb de primera clase; no se requiere panel SaaS.

Opcional PostgreSQL

MariaDB por defecto; instale PostgreSQL con un comando y elija un motor por aplicación (cipi db install pgsql).

Instale Cipi en un solo comando

Ejecute un Ubuntu VPS nuevo y luego ejecute:

wget -O - https://cipi.sh/setup.sh | fiesta

Eso instala y configura la pila de producción completa: Nginx, PHP-FPM / Laravel Octane, MariaDB, opcional PostgreSQL, Redis y Supervisor. Ver el guía de introducción.

Donde moss.sh es la mejor opción

moss.sh es una buena opción si desea una web GUI pulida, monitoreo integrado, flujos de trabajo de agencia para administrar servidores de clientes y un inicio rápido para equipos que no pertenecen a CLI, similar a Ploi. Si su equipo prefiere hacer clic en lugar de escribir y usted se siente cómodo con una suscripción mensual a SaaS, vale la pena evaluar moss.sh.

Cómo migrar de moss.sh a Cipi

Pasar de moss.sh a Cipi es una transición limpia en lugar de una conversión in situ: se levanta un servidor nuevo junto a su configuración actual, implemente desde el mismo repositorio de Git y cambie DNS cuando todo está comprobado. No es necesario cambiar su base de código Laravel.

  1. Realice un inventario en moss.sh. Anote sus servidores, sitios y configuraciones de implementación en el panel moss.sh y descargue cada base de datos que necesite mover.
  2. Aprovisione un Ubuntu VPS nuevo e instale Cipi. Cualquier proveedor funciona (Hetzner, DigitalOcean, Vultr, Linode, AWS). El Ubuntu 24.04/26.04 ejecutar wget -O - https://cipi.sh/setup.sh | bash y la pila de producción completa (Nginx, PHP, MariaDB, Valkey, Supervisor) se configura en minutos.
  3. Recrea cada aplicación y conecta Git. cipi app create aprovisiona una aplicación aislada con su propio usuario del sistema, base de datos, grupo PHP y Nginx vhost (agregue --octane para Laravel Octane). La conexión de GitHub o GitLab configura las claves de implementación y los webhooks automáticamente para implementaciones sin tiempo de inactividad.
  4. Mueve datos y corta. Importe el volcado de su base de datos, copie su .env valores, emita HTTPS certificados con cipi ssl install, luego apunte DNS al nuevo servidor y retire la configuración anterior.

Cipi usa las convenciones estándar Nginx, PHP-FPM / Laravel Octane y del implementador, por lo que no hay configuración específica del proveedor para deshacerla más tarde. Detalles completos en el guía de introducción.

Preguntas frecuentes

¿Es Cipi una buena alternativa a moss.sh para Laravel?

Sí. Ambos admiten PHP, Laravel y Node en Ubuntu con implementaciones de Git. moss.sh es un administrador de sistemas virtual SaaS de $9 a 49/mes con GUI y flujos de trabajo de agencia; Cipi es gratuito, open-source, self-hosted, CLI-first, con implementaciones ilimitadas, cifrado de configuración dual MCP, AES-256 y sincronización de servidor.

¿Cuál es la diferencia entre Cipi y moss.sh?

moss.sh es un panel de administración de servidor SaaS con GUI web, monitoreo y flujos de trabajo de agencia, facturado entre $ 9 y 49 por mes con un nivel gratuito limitado a 25 implementaciones de git por mes. Cipi es un open-source CLI gratuito que se ejecuta completamente en su VPS, está diseñado específicamente para Laravel con integración de Deployer y agrega un servidor REST API, doble MCP, cifrado en reposo y sincronización de servidor a servidor.

¿Cipi tiene límites de implementación como el nivel gratuito de moss.sh?

No. Los límites de niveles gratuitos de moss.sh se implementan en 25 por mes. Cipi no tiene cuotas de implementación ni límites de ningún tipo: implemente con la frecuencia que desee, en tantos servidores y aplicaciones como desee, de forma gratuita.

¿Cuándo debería seguir eligiendo moss.sh?

Elija moss.sh si desea una web GUI pulida, monitoreo integrado, flujos de trabajo de agencia para administrar servidores de clientes y un inicio rápido para equipos que no pertenecen a CLI, y se siente cómodo con una suscripción mensual a SaaS.

¿Puedo migrar de moss.sh a Cipi?

Sí. Proporcione un Ubuntu VPS nuevo, instale Cipi con un comando, vuelva a crear cada sitio con la creación de la aplicación cipi, conecte su repositorio GitHub o GitLab para implementaciones sin tiempo de inactividad, importe el volcado de su base de datos y luego apunte DNS al nuevo servidor. Su base de código Laravel en sí no necesita cambios.

¿Cipi tiene un panel web como moss.sh?

Sí, opcionalmente. Al ejecutar cipi gui tudominio.com se instala un panel de control web self-hosted gratuito que administra uno o más Cipi servidores desde el navegador: aplicaciones, bases de datos, SSL, implementaciones y registros. A diferencia de moss.sh, el panel es opcional y se ejecuta en su propia infraestructura; Cipi sigue siendo totalmente utilizable solo desde CLI.
