20i-Alternative

Die self-hosted 20i-Alternative für Laravel

Vergleich zuletzt aktualisiert: 7. September 2026 · spiegelt Cipi 5 und aktuelle 20i-Produkte wider

20i ist ein vollständiges Hosting-Unternehmen – Reseller-Tarife, Managed Cloud, WordPress, VPS, Domains und das My20i-Panel, mit über 60 Rechenzentren und 24×7-Support. Cipi ist kein Hosting-Unternehmen: Sie bringen jedes Ubuntu-VPS mit, erhalten eine Laravel-first Deploy-CLI, vollen Root und eine feste Rechnung. Kostenlos, open source und gebaut für Entwickler, die den Server bereits besitzen.

Warum Teams Cipi gegenüber 20i wählen

Ein Deploy-Tool, kein Hosting-Vertrag

Cipi ist kostenlose Software auf einem VPS, das Sie bereits bezahlen. 20i ist ein Hosting-Anbieter – Reseller, Cloud, WordPress und VPS-Produkte, abgerechnet über ihre Plattform.

Sie wählen den Anbieter

Vollständiger Root auf Hetzner, OVH, DigitalOcean, AWS oder Bare Metal. 20i hostet auf 20iCloud, AWS oder Google Cloud unter ihrem Panel.

Laravel-first, nicht generisches Hosting

Octane, Horizon, Reverb, Deployer, artisan und Queue-Worker sind eingebaut. 20i ist auf Agenturen, WordPress, Magento/WooCommerce und Reseller-Workflows ausgerichtet.

CLI, API und duales MCP

Alles ist über SSH skriptbar. 20i ist Panel-first (My20i / StackCP) mit Git – keine KI-native, Pipeline-first Laravel-CLI.

Open source & keine Panel-Bindung

MIT-lizenziert und überprüfbar. 20i zu verlassen heißt, ihr Control Panel, CDN und Reseller-Tooling zu verlassen; Cipi zu verlassen hinterlässt eine Standard-LEMP-Box.

Verschlüsselung im Ruhezustand + Souveränität

Alle Konfigurationen werden mit AES-256-CBC auf einem VPS in der von Ihnen gewählten Region verschlüsselt – keine Infrastrukturdaten verlassen Ihren Computer.

Laravel Octane (FrankenPHP)

Erstellen oder konvertieren Sie Apps mit cipi app create --octane / cipi app convert --to=octane. Führen Sie Octane neben klassischen FPM-Apps auf demselben Server aus.

Optional PostgreSQL

MariaDB standardmäßig; Installieren Sie PostgreSQL mit einem Befehl und wählen Sie eine Engine pro App aus (cipi db install pgsql).

Installieren Sie Cipi in einem Befehl

Starten Sie ein neues Ubuntu VPS und führen Sie dann Folgendes aus:

wget -O - https://cipi.sh/setup.sh | bash

Dadurch wird der gesamte Produktionsstapel installiert und konfiguriert – Nginx, PHP-FPM / Laravel Octane, MariaDB, optional PostgreSQL, Redis und Supervisor. Siehe die Leitfaden für den Einstieg.

Wobei 20i die bessere Wahl ist

20i überzeugt als Hosting-Unternehmen: 24×7 menschlicher Support, ein kostenloses CDN, One-Click-Migrationen, über 60 Rechenzentren, Reseller-/StackCP-Branding, Domains, E-Mail, WordPress Manager, Agency Hub und Angaben zu grüner Energie. Wenn Sie Hosting verkaufen, WordPress in großem Maßstab brauchen oder einen einzigen Anbieter für Sites, Mail und DNS wollen, ist 20i die bessere Lösung. Cipi ist für Entwickler, die bereits ein VPS haben und Laravel-Deploys ohne Hosting-Panel wollen.

So migrieren Sie von 20i zu Cipi

Der Wechsel von 20i zu Cipi ist eine saubere Umstellung: Sie stellen ein neues Ubuntu-VPS auf, deployen aus demselben Git-Repository, importieren Daten und wechseln DNS, wenn alles passt. Ihre Laravel-Codebasis muss nicht geändert werden.

  1. Exportieren Sie Ihre Daten aus 20i. Nutzen Sie ihr Migration Center oder erstellen Sie einen Datenbank-Dump und eine Dateikopie aus My20i. Notieren Sie PHP-Version, Cron, Mail und DNS, damit Sie unterscheiden können, was Cipi übernehmen soll und was Sie woanders behalten.
  2. Stellen Sie ein neues Ubuntu VPS bereit und installieren Sie Cipi. Jeder Anbieter funktioniert (Hetzner, DigitalOcean, Vultr, Linode, AWS). Auf Ubuntu 24.04/26.04 führen Sie wget -O - https://cipi.sh/setup.sh | bash aus und der gesamte Produktionsstapel – Nginx, PHP, MariaDB, Valkey, Supervisor – ist in wenigen Minuten konfiguriert.
  3. Erstellen Sie jede App neu und verbinden Sie Git. cipi app create stellt eine isolierte App mit eigenem Systembenutzer, eigener Datenbank, PHP-Pool und Nginx-vhost bereit (fügen Sie --octane für Laravel Octane hinzu). Durch die Verbindung von GitHub oder GitLab werden Bereitstellungsschlüssel und Webhooks automatisch für Bereitstellungen ohne Ausfallzeiten konfiguriert.
  4. Daten verschieben und umschneiden. Importieren Sie Ihren Datenbank-Dump, kopieren Sie Ihre .env-Werte, stellen Sie HTTPS-Zertifikate mit cipi ssl install aus und richten Sie dann DNS auf den neuen Server.

Cipi verwendet die Standardkonventionen Nginx, PHP-FPM / Laravel Octane und Deployer, daher gibt es keine herstellerspezifische Konfiguration zum späteren Abwickeln. Ausführliche Informationen finden Sie in der Leitfaden für den Einstieg.

Häufig gestellte Fragen

Ist Cipi eine Alternative zu 20i?

Für Laravel-Application-Hosting ja. Cipi ist eine kostenlose open-source Deploy-CLI, die Sie auf Ihrem eigenen Ubuntu-VPS installieren. 20i ist ein Hosting-Unternehmen mit Reseller-, WordPress-, Cloud- und VPS-Produkten – eine andere Kategorie, wenn Sie Domains, E-Mail oder White-Label-Hosting brauchen.

Was ist der Unterschied zwischen Cipi und 20i?

20i verkauft verwaltetes Hosting über My20i, mit CDN, Migrationen und 24×7-Support. Cipi verkauft kein Hosting: Es richtet einen Laravel-Produktionsstack auf einem VPS ein, das Sie bereits besitzen, mit CLI, REST API, dualem MCP und AES-256-Konfigurationsverschlüsselung.

Ist Cipi günstiger als 20i?

Cipi selbst ist kostenlos; Sie zahlen nur das VPS. 20i-Preise hängen vom Produkt ab (Reseller, Managed Cloud ab etwa 10,99 $/Monat, WordPress, VPS). Vergleichen Sie VPS plus Cipi mit dem 20i-Tarif, der zu Ihren Sites passt.

Wann sollte ich mich noch für 20i entscheiden?

Wählen Sie 20i, wenn Sie einen Hosting-Anbieter mit 24×7-Support, Reseller-Branding, WordPress-Tooling, Domains, E-Mail und einem globalen CDN wollen – nicht eine Do-it-yourself-Laravel-CLI auf einem nackten VPS.

Kann ich von 20i zu Cipi migrieren?

Ja für Laravel- (und andere PHP-)Apps. Stellen Sie ein Ubuntu-VPS bereit, installieren Sie Cipi, erstellen Sie jede Site neu, importieren Sie Datenbank und Dateien und richten Sie DNS ein. Behalten Sie 20i für Mail oder Domains, wenn Sie diese Produkte noch brauchen.

Enthält Cipi ein Control Panel wie My20i?

Optional. Mit cipi gui yourdomain.com installieren Sie ein kostenloses, self-hosted Web-Panel. Anders als My20i ist es opt-in und läuft auf Ihrer Infrastruktur; Cipi bleibt allein über die CLI voll nutzbar.
