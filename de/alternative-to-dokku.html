Dokku Alternative

Der Laravel-native Dokku Alternative

Vergleich zuletzt aktualisiert: 4. August 2026 · spiegelt Cipi 5 und aktuelle Dokku Preise/Funktionen wider

Dokku und Cipi sind beide kostenlos und open source (MIT). Dokku ist ein self-hosted Heroku – Git-Push zur Bereitstellung von Docker-Containern mit einem umfangreichen Plugin-Ökosystem. Cipi ist Laravel-first, führt Apps auf einem nativen LEMP-Stack aus und fügt vollständige Serververwaltung CLI, Deployer, duales MCP, Verschlüsselung im Ruhezustand und Serversynchronisierung hinzu.

Warum Laravel Teams Cipi gegenüber Dokku bevorzugen

Gebaut für Laravel

Deployer, artisan-Verknüpfungen, automatische Warteschlangenarbeiter und Git-Bereitstellungen ohne Ausfallzeiten sind integriert – Dokku behandelt PHP als eines von vielen Container-Buildpacks.

Native LEMP, nein Docker

Führen Sie PHP-FPM direkt auf dem Host aus, um den Speicherbedarf zu senken, das Debuggen zu vereinfachen und keine Containerschicht zu warten.

Vollständige Serververwaltung CLI

Stellen Sie Server bereit, verwalten Sie SSL, Datenbanken und den gesamten App-Lebenszyklus – nicht nur Git-Push-Bereitstellungen im PaaS-Stil.

Webhook Bereitstellung ohne Ausfallzeiten

Atomare Freigaben mit einem Befehl für GitHub und GitLab – konzipiert für Laravel, nicht angeschraubt.

KI-nativ mit dualem MCP

App-spezifische und globale MCP-Server für eine vollständige KI-gesteuerte Infrastrukturverwaltung von jedem MCP-kompatiblen Agenten.

Verschlüsselung im Ruhezustand und Serversynchronisierung

AES-256-CBC Vault-Verschlüsselung für alle Konfigurationen sowie integrierte verschlüsselte Server-zu-Server-Synchronisierung für Failover-Replikation.

Laravel Octane (FrankenPHP)

Erstellen oder konvertieren Sie Apps mit cipi app create --octane / cipi app convert --to=octane. Führen Sie Octane neben klassischen FPM-Apps sowie erstklassige Horizon und Reverb aus – kein SaaS-Panel erforderlich.

Optional PostgreSQL

MariaDB standardmäßig; Installieren Sie PostgreSQL mit einem Befehl und wählen Sie eine Engine pro App aus (cipi db install pgsql).

Installieren Sie Cipi in einem Befehl

Starten Sie ein neues Ubuntu VPS und führen Sie dann Folgendes aus:

wget -O - https://cipi.sh/setup.sh | bash

Dadurch wird der gesamte Produktionsstapel installiert und konfiguriert – Nginx, PHP-FPM / Laravel Octane, MariaDB, optional PostgreSQL, Redis und Supervisor. Siehe die Leitfaden für den Einstieg.

Wobei Dokku die bessere Wahl ist

Dokku ist ein ausgezeichnetes self-hosted PaaS, wenn Sie Git-Push-Einfachheit, ein umfangreiches Plugin-Ökosystem, Container-Workflows und eine minimale Lernkurve für Heroku-Flüchtlinge wünschen. Wenn Ihr Workflow „Git Push First“ ist und Sie Wert auf Containerisolation gegenüber Laravel-spezifischer Automatisierung oder einem nativen PHP-Stack legen, ist Dokku eine Evaluierung wert.

So migrieren Sie von Dokku zu Cipi

Der Wechsel von Dokku zu Cipi ist eher eine saubere Umstellung als eine direkte Konvertierung: Sie stehen vor einem Erstellen Sie einen neuen Server neben Ihrem aktuellen Setup, stellen Sie ihn aus demselben Git-Repository bereit und wechseln Sie DNS, wenn alles passt. Ihre Laravel-Codebasis muss nicht geändert werden.

  1. Machen Sie eine Bestandsaufnahme Ihrer Dokku Apps. Listen Sie Ihre Apps mit dokku apps:list auf und exportieren Sie Datenbanken aus den von Ihnen verwendeten Postgres- oder MySQL-Plugins.
  2. Stellen Sie ein neues Ubuntu VPS bereit und installieren Sie Cipi. Jeder Anbieter funktioniert (Hetzner, DigitalOcean, Vultr, Linode, AWS). Am Ubuntu 24.04/26.04 ausgeführt wget -O - https://cipi.sh/setup.sh | bash und der gesamte Produktionsstapel – Nginx, PHP, MariaDB, Valkey, Supervisor – ist in wenigen Minuten konfiguriert.
  3. Erstellen Sie jede App neu und verbinden Sie Git. cipi app create Stellt eine isolierte App mit eigenem Systembenutzer, eigener Datenbank, PHP-Pool und Nginx vhost bereit (hinzufügen --octane für Laravel Octane). Durch die Verbindung von GitHub oder GitLab werden Bereitstellungsschlüssel und Webhooks automatisch für Bereitstellungen ohne Ausfallzeiten konfiguriert.
  4. Daten verschieben und umschneiden. Importieren Sie Ihren Datenbank-Dump, kopieren Sie Ihren .env Werte, stellen Sie HTTPS Zertifikate aus mit cipi ssl install, richten Sie dann DNS auf den neuen Server und stellen Sie das alte Setup ein.

Cipi verwendet die Standardkonventionen Nginx, PHP-FPM / Laravel Octane und Deployer, daher gibt es keine Herstellerspezifische Konfiguration zum späteren Abwickeln. Ausführliche Informationen finden Sie in der Leitfaden für den Einstieg.

Häufig gestellte Fragen

Ist Cipi eine gute Dokku-Alternative für Laravel?

Ja. Beide sind kostenlos und open source. Dokku ist ein self-hosted PaaS im Heroku-Stil mit Git Push Docker-Bereitstellungen; Cipi ist Laravel-first, führt Apps auf einem nativen LEMP-Stack mit Deployer, artisan, Warteschlangen, dualem MCP, Verschlüsselung im Ruhezustand und vollständiger Serververwaltung CLI aus.

Was ist der Unterschied zwischen Cipi und Dokku?

Dokku stellt Anwendungen als Docker-Container über Git Push mit einem Plugin-Ökosystem bereit – ideal für Workflows im Heroku-Stil. Cipi installiert und verwaltet einen herkömmlichen LEMP-Stack direkt auf Ubuntu, wird über CLI betrieben und ist speziell für Laravel mit Deployer-Integration, automatischen Warteschlangenarbeitern, AES-256-Konfigurationsverschlüsselung und Serversynchronisierung entwickelt.

Verwendet Cipi Docker wie Dokku?

Nein. Dokku ist Container-First – jede App wird in Docker über Git Push ausgeführt. Cipi verwendet einen nativen Nginx-, PHP-FPM-, MariaDB- (optional PostgreSQL) und Supervisor-Stack auf dem Host-Betriebssystem. Für Standard-Laravel-Apps bedeutet dies einen geringeren Overhead, ein einfacheres Debugging und keine zu verwaltende Containerschicht.

Wann sollte ich noch Dokku wählen?

Wählen Sie Dokku, wenn Sie Git-Push-Einfachheit, ein umfangreiches Plugin-Ökosystem, Container-Workflows und eine minimale Lernkurve für Heroku-Flüchtlinge wünschen – und Sie keine Laravel-spezifische Automatisierung, einen nativen PHP-Stack oder eine vollständige Serververwaltung über PaaS-Bereitstellungen hinaus benötigen.

Kann ich von Dokku zu Cipi migrieren?

Ja. Stellen Sie ein neues Ubuntu VPS bereit, installieren Sie Cipi mit einem Befehl, erstellen Sie jede App mit cipi app create neu, verbinden Sie Ihr GitHub- oder GitLab-Repository für Bereitstellungen ohne Ausfallzeiten, importieren Sie Ihren Datenbank-Dump und verweisen Sie dann DNS auf den neuen Server. Es sind keine Buildpacks oder Docker-Dateien erforderlich.

Unterstützt Cipi Push-to-Deploy wie Dokku?

Ja, über Git-Webhooks: Verbinden Sie GitHub oder GitLab einmal und jeder Push an Ihren Produktionszweig löst eine Bereitstellung ohne Ausfallzeiten aus – derselbe Workflow, ohne dass Buildpacks oder Container beteiligt sind.
