RunCloud Alternative

Der kostenlose, Laravel-native RunCloud Alternative

Vergleich zuletzt aktualisiert: 4. August 2026 · spiegelt Cipi 5 und aktuelle RunCloud Preise/Funktionen wider

RunCloud ist ein PHP-Bedienfeld, aber es ist nicht Laravel-nativ – der Einsatz von Laravel bedeutet eine Verkabelung Deployer, Warteschlangen und artisan von Hand. Cipi versteht Laravel sofort: automatischer Deployer Integration, Warteschlangenarbeiter, Releases ohne Ausfallzeiten – kostenlos, open source und vollständig CLI-gesteuert auf eigene Faust Ubuntu VPS.

Warum Laravel-Entwickler von RunCloud zu Cipi wechseln

Laravel-native, Nullkonfiguration

Cipi konfiguriert den Deployer, artisan Verknüpfungen, Supervisor Warteschlangenarbeiter und die gemeinsame Verzeichnisstruktur automatisch. RunCloud erfordert eine manuelle Verkabelung.

$0 instead of $12–18/mo

RunCloud Rechnungen pro Server und Monat. Cipi ist für alle Ihre Server für immer kostenlos.

Echte Releases ohne Ausfallzeiten

Webhook-gesteuerte, atomare Releases für GitHub und GitLab in einem Befehl – keine handgeschriebenen Bereitstellungsskripts.

Keine SaaS-Abhängigkeit

Cipi läuft vollständig auf Ihrem VPS; RunCloud verwaltet Server über sein eigenes Cloud-Panel.

KI-nativ mit dualem MCP

Verwalten Sie Apps, Bereitstellungen und SSL auf dem gesamten Server von jeder MCP-kompatiblen IDE oder jedem Agenten aus.

Open source & im Ruhezustand verschlüsselt

MIT-lizenziert und überprüfbar, alle Konfigurationen werden mit AES-256-CBC auf Ihrem Server verschlüsselt.

Laravel Octane (FrankenPHP)

Erstellen oder konvertieren Sie Apps mit cipi app create --octane / cipi app convert --to=octane. Führen Sie Octane neben klassischen FPM-Apps sowie erstklassige Horizon und Reverb aus – kein SaaS-Panel erforderlich.

Optional PostgreSQL

MariaDB standardmäßig; Installieren Sie PostgreSQL mit einem Befehl und wählen Sie eine Engine pro App aus (cipi db install pgsql).

Installieren Sie Cipi in einem Befehl

Starten Sie ein neues Ubuntu VPS und führen Sie dann Folgendes aus:

wget -O - https://cipi.sh/setup.sh | bash

Dadurch wird der gesamte Produktionsstapel installiert und konfiguriert – Nginx, PHP-FPM / Laravel Octane, MariaDB, optional PostgreSQL, Redis und Supervisor. Siehe die Leitfaden für den Einstieg.

Wobei RunCloud immer noch die bessere Wahl ist

RunCloud unterstützt sowohl Nginx als auch Apache und ist beliebt für WordPress und generisches PHP-Hosting mit einem freundliches visuelles Panel. Wenn Ihre Arbeitslast hauptsächlich aus WordPress oder Nicht-Laravel PHP besteht und Sie GUI bevorzugen, RunCloud ist eine vernünftige Lösung.

So migrieren Sie von RunCloud zu Cipi

Der Wechsel von RunCloud zu Cipi ist eher eine saubere Umstellung als eine direkte Konvertierung: Sie stehen vor einem Erstellen Sie einen neuen Server neben Ihrem aktuellen Setup, stellen Sie ihn aus demselben Git-Repository bereit und wechseln Sie DNS, wenn alles passt. Ihre Laravel-Codebasis muss nicht geändert werden.

  1. Führen Sie eine Bestandsaufnahme im Bereich RunCloud durch. Listen Sie Ihre Webanwendungen, cron-Jobs, supervisor-Jobs und Datenbanken auf, damit Sie sie auf dem neuen Server neu erstellen können.
  2. Stellen Sie ein neues Ubuntu VPS bereit und installieren Sie Cipi. Jeder Anbieter funktioniert (Hetzner, DigitalOcean, Vultr, Linode, AWS). Am Ubuntu 24.04/26.04 ausgeführt wget -O - https://cipi.sh/setup.sh | bash und der gesamte Produktionsstapel – Nginx, PHP, MariaDB, Valkey, Supervisor – ist in wenigen Minuten konfiguriert.
  3. Erstellen Sie jede App neu und verbinden Sie Git. cipi app create Stellt eine isolierte App mit eigenem Systembenutzer, eigener Datenbank, PHP-Pool und Nginx vhost bereit (hinzufügen --octane für Laravel Octane). Durch die Verbindung von GitHub oder GitLab werden Bereitstellungsschlüssel und Webhooks automatisch für Bereitstellungen ohne Ausfallzeiten konfiguriert.
  4. Daten verschieben und umschneiden. Importieren Sie Ihren Datenbank-Dump, kopieren Sie Ihren .env Werte, stellen Sie HTTPS Zertifikate aus mit cipi ssl install, richten Sie dann DNS auf den neuen Server und stellen Sie das alte Setup ein.

Cipi verwendet die Standardkonventionen Nginx, PHP-FPM / Laravel Octane und Deployer, daher gibt es keine Herstellerspezifische Konfiguration zum späteren Abwickeln. Ausführliche Informationen finden Sie in der Leitfaden für den Einstieg.

Häufig gestellte Fragen

Gibt es eine kostenlose Alternative zu RunCloud?

Ja. Cipi ist eine kostenlose open-source (MIT) und self-hosted Alternative zu RunCloud. Es installiert und verwaltet einen vollständigen Produktionsstack auf jedem Ubuntu VPS ohne monatliches Abonnement und ohne Gebühr pro Server.

Was ist der Unterschied zwischen Cipi und RunCloud?

RunCloud ist ein PHP-orientiertes SaaS-Kontrollfeld (12–18 $/Monat pro Server), das nicht Laravel-nativ ist: kein integrierter Deployer, keine artisan-Verknüpfungen und keine automatische Supervisor-Konfiguration für Laravel-Warteschlangen. Cipi ist Laravel-nativ und erledigt all dies automatisch und kostenlos von CLI.

Ist Cipi besser als RunCloud für Laravel?

Speziell für Laravel bietet Ihnen Cipi viel mehr sofort einsatzbereit – automatische Deployer-Integration, artisan-Befehle, Warteschlangenarbeiter und Releases ohne Ausfallzeiten – und das ohne Kosten. RunCloud erfordert eine manuelle Konfiguration der Teile, Cipi erfolgt automatisch.

Wann sollte ich noch RunCloud wählen?

Wählen Sie RunCloud, wenn Sie hauptsächlich WordPress- oder generische PHP-Apps hosten, neben Nginx auch Apache-Unterstützung benötigen und ein visuelles Web-Panel einem CLI-First-Workflow vorziehen.

Kann ich von RunCloud zu Cipi migrieren?

Ja. Stellen Sie ein neues Ubuntu VPS bereit, installieren Sie Cipi mit einem Befehl, erstellen Sie jede App mit cipi app create neu, verbinden Sie Ihr GitHub- oder GitLab-Repository für Bereitstellungen ohne Ausfallzeiten, importieren Sie Ihren Datenbank-Dump und verweisen Sie dann DNS auf den neuen Server. Ihre Laravel-Codebasis selbst benötigt keine Änderungen.

Verfügt Cipi über ein Web-Dashboard wie RunCloud?

Ja, optional. Wenn Sie cipi gui yourdomain.com ausführen, wird ein kostenloses self-hosted Web-Kontrollfeld installiert, das einen oder mehrere Cipi Server über den Browser verwaltet – Apps, Datenbanken, SSL, Bereitstellungen und Protokolle. Im Gegensatz zu RunCloud ist das Dashboard optional und läuft auf Ihrer eigenen Infrastruktur; Cipi bleibt allein vom CLI voll nutzbar.
