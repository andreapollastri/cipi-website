Laravel-first open-source CLI mit AI und MCP – auch statische Websites und generisches PHP. Ein Befehl installiert den Stack. Ein Befehl erstellt eine isolierte App mit Datenbank. Worker, SSL und Bereitstellungen ohne Ausfallzeiten.

Cipi wird mit einem integrierten Gerät geliefert MCP Servergebrauchsfertig. Fernverwaltung

Ihr Server,
von jedes Terminal.

cipi-cli ist eine eigenständige Go-Binärdatei das mit dem Cipi REST API von Ihrem lokalen Computer kommuniziert. Kein SSH erforderlich – Apps verwalten, Datenbanken, SSL-Zertifikate und Bereitstellungen von jedem Terminal aus. Verfügbar für Linux und macOS.

  • Vollständiger App-Lebenszyklus – Erstellen, Bearbeiten, Bereitstellen und Löschen von Ihrem Computer
  • Datenbankverwaltung – Passwörter erstellen, sichern, wiederherstellen und rotieren
  • SSL-Bereitstellung – Installieren Sie Let's Encrypt-Zertifikate mit einem Befehl
  • Multi-Server-Profile – ein Profil pro Server, Wechsel mit einem Präfix
  • Globale Statusübersicht – CPU, RAM, Festplatte, Apps und Dienste auf allen Servern
  • Domänenaliase – Aliase pro App hinzufügen, auflisten und entfernen
  • Shell-Vervollständigung – Ein-Befehl-Installation für ZSH, Bash und Fish
  • JSON-Ausgabe – weiterleiten an jqfür Skripterstellung und CI/CD-Pipelines
  • Open source, MIT-lizenziert – vorgefertigte Binärdateien und Build aus dem Quellcode

Optionales Webpanel

Ein GUI, nur wenn
Du willst eins.

Cipi ist CLI-first – und wird es immer sein. Aber wenn ein Browser-Dashboard passt Sie oder Ihre Kunden besser, ein einziger Befehl installiert die optional Webkontrolle Panel: eine self-hosted Laravel App, die einen oder mehrere Cipi Server über denselben REST API verwaltet. Brauchen Sie es nicht? Installieren Sie es nicht – es ändert sich nichts.

  • Ein Befehl zur Installation – cipi gui panel.example.com
  • Verwalten Sie Apps, SSL, Protokolle und Datenbanken über den Browser
  • Ein Panel, viele Server – ein leichtes Multi-Server-Cockpit
  • Sitzungsanmeldung mit optionaler TOTP-Zwei-Faktor-Authentifizierung
  • Self-hosted und open source – Ihr Panel, Ihr Server, Ihre Daten
  • Jederzeit deinstallieren – cipi gui remove – zurück zum reinen CLI

FAQ

Fragen, die die Leute stellen, bevor sie installieren

Was ist Cipi?

Cipi ist ein Laravel-first, open-source bereitgestelltes CLI, das auch statische Websites und generische PHP-Apps unterstützt. Ein einzelner Befehl installiert einen vollständigen Produktionsstapel (Nginx, PHP-FPM oder Laravel Octane, MariaDB, Valkey, Supervisor) auf jedem Ubuntu VPS.

Ist Cipi kostenlos?

Ja. Cipi ist 100 % kostenlos und open source steht unter der MIT-Lizenz. Sie hosten es selbst auf Ihrem eigenen Server, ohne Abonnement oder Gebühren pro Server.

Wie installiere ich Cipi?

Führen Sie einen einzelnen Befehl auf einem neuen Ubuntu VPS aus: wget -O - https://cipi.sh/setup.sh | bash. Der vollständige LEMP-Produktionsstapel wird automatisch installiert und konfiguriert.

Ist Cipi eine Alternative zu Laravel Forge?

Ja. Cipi ist eine kostenlose self-hosted, open-source Alternative zu Laravel Forge und ähnlichen Bereitstellungstools, die Ihnen die volle Kontrolle über Ihre Server ohne wiederkehrende Kosten gibt. Siehe die Laravel Forge Vergleich.

Welche Server unterstützt Cipi?

Cipi läuft auf jedem Ubuntu VPS von Anbietern wie DigitalOcean, Hetzner, Vultr, Linode, AWS und anderen und verwandelt einen einzelnen Server in eine Multi-App-Hosting-Plattform LEMP.

Unterstützt Cipi Laravel Octane?

Ja. Cipi führt Laravel Octane nativ auf FrankenPHP aus: Erstellen Sie Octane Apps mit cipi app create --octane oder konvertieren Sie bestehende Apps mit cipi app convert --to=octane, läuft neben klassischen PHP-FPM-Apps auf demselben Server.

Verfügt Cipi über ein Web-Kontrollfeld?

Ja, optional. Cipi ist CLI-first, aber cipi gui yourdomain.com Installiert ein kostenloses self-hosted Web-Dashboard, das einen oder mehrere Cipi Server über den Browser verwaltet – Apps, Datenbanken, SSL, Bereitstellungen und Protokolle.

Können KI-Agenten einen Cipi-Server verwalten?

Ja. Cipi verfügt über einen dualen MCP (Model Context Protocol)-Server, sodass MCP-kompatible IDEs und KI-Agenten über ein strukturiertes API Apps erstellen, Bereitstellungen ausführen, SSL und Datenbanken verwalten können.
