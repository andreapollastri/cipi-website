git push.
Das ist die ganze Pipeline.

Verbinden Sie GitHub oder GitLab einmal und Cipi erledigt den Rest: Bereitstellung generierter und injizierter Schlüssel, Webhooks erstellt, jede App wird mit einem eigenen Linux-Benutzer, einer eigenen Datenbank, einem eigenen Vhost und einem eigenen PHP-FPM-Pool bereitgestellt. Drücken Sie zu Ihrem Branch und eine signaturverifizierte Bereitstellung ohne Ausfallzeiten werden im Hintergrund ausgeführt – mit nur einem Befehl Rollback, falls Sie es jemals brauchen. Es müssen keine CI/CD gewartet werden. Keine Pipeline YAML zum Weinen.

cipi.yml

Konfiguration, die mit dem Code reist.

Eine Datei neben der App committen: Domain-Aliase, PHP-Version und php.ini, extra Datenbanken, Queue-Worker oder Horizon, Laravel Reverb, den Scheduler, einen Healthcheck und Backup-Profile. Vom Server generieren, den Plan prüfen, anwenden — oder opt-in, damit jeder erfolgreiche Deploy abgeglichen wird. Das Schema enthält keine Shell-Befehle; eine ungültige Datei wird als Ganzes abgelehnt, nie halb angewendet.

generate plan apply auto on deploy

Festung

Gehärtet vor Ihrem Erster Login.

Nur-SSH-Schlüsselauthentifizierung, Fail2ban mit progressivem Sperren, UFW-Firewall, unbeaufsichtigte Sicherheit Upgrades, ein AES-256-Tresor für alle Anmeldeinformationen, DSGVO-konforme Protokollaufbewahrung und vollwertiger Linux-Benutzer Isolation pro App. E-Mail-Benachrichtigungen werden bei Einbruchsversuchen, sudo-Erhöhungen, SSH-Schlüsseländerungen usw. ausgelöst fehlgeschlagene Bereitstellungen – während alles in einem manipulationssicheren Ereignisprotokoll landet. Sicherheit ist für Sie kein Merkmal aktivieren. Es handelt sich um die Standardeinstellung, an deren Entfernung Sie arbeiten müssten.

Belastbarkeit

Der Verlust eines Servers kostet Sie ein Befehl.

Code, Datenbank, .env und Speicher – verschlüsselt und termingerecht an jeden S3-kompatiblen Bucket versendet. Stellen Sie eine Datenbank mit einem Befehl wieder her und setzen Sie mit einem anderen ein Release zurück. Und wenn es Zeit ist zu migrieren oder erholen, cipi sync klont Apps, Datenbanken, Konfigurationen und SSL-Zertifikate auf einen neuen Server über eine einzige AES-256-Verschlüsselung übertragen. Disaster Recovery ist kein Projekt mehr, sondern ein Befehl.

Bereitstellung & Leistung

Installation mit nur einem Befehl

Ein einziges Skript verwandelt einen frischen Ubuntu VPS in einen kompletten Produktionsstapel: Nginx, PHP 8,5, MariaDB oder PostgreSQL, Valkey, Supervisor, Deployer, Certbot.

Tiefer Tauchgang

Octane auf FrankenPHP

Servieren Sie jede App mit Laravel Octane, angetrieben von FrankenPHP für absolute Geschwindigkeit, oder klassisch kampferprobte PHP-FPM. Eine Flagge pro App, Ihr Anruf.

Tiefer Tauchgang

MariaDB oder PostgreSQL

MariaDB standardmäßig, PostgreSQL einen Befehl entfernt. Wählen Sie die Engine pro App aus – .env und Verbindung URLs folgen automatisch.

Tiefer Tauchgang

Valkey Cache und Warteschlangen

Ein Redis-kompatibler In-Memory-Speicher für Cache, Sitzungen und Warteschlangen – installiert, gesichert und sofort in jede App integriert.

Tiefer Tauchgang

Horizon & Reverb

Laravel Horizon Beobachten Sie Ihre Warteschlangen und Reverb Websockets hinter Nginx mit SSL – bereitgestellt und betreut für Sie.

Tiefer Tauchgang

Vollständig isolierte Apps

Jede App erhält ihren eigenen Linux-Benutzer, ihre eigene Datenbank, Nginx vhost, PHP-FPM-Pool und Worker. Eins Eine kompromittierte App berührt niemals eine andere.

Tiefer Tauchgang

Bereitstellung ohne Ausfallzeiten

Deployer-basierte atomare Releases mit Symlink-Umschaltung und Rollback mit einem Befehl. Ihre Benutzer niemals siehe eine Wartungsseite.

Tiefer Tauchgang

git push auto-deploy

Durch die HMAC-Signatur verifizierte Webhooks lösen bei jedem Push Hintergrundbereitstellungen aus. Zweigfilterung inklusive, CI/CD Rohrleitung nicht erforderlich.

Tiefer Tauchgang

cipi.yml

Konfiguration, die mit dem Code kommt: Aliase, PHP, Datenbanken, Worker, Reverb, Scheduler, Healthcheck und Backups — geplant, angewendet oder bei jedem Deploy abgeglichen.

Tiefer Tauchgang

Automatisch SSL

Let's Encrypt Zertifikate werden automatisch installiert und erneuert – Wildcard-Domänen werden unterstützt. HTTPS ist ein Befehl, dann ist er für immer.

Tiefer Tauchgang
B

Jede App, jede Schnittstelle

Nicht nur Laravel

Benutzerdefinierte Apps bieten Nginx + PHP-FPM mit einem klassischen htdocs-Root – perfekt für statische Websites, SPAs, WordPress, Symfony oder einfach PHP. SFTP-fähig.

Tiefer Tauchgang

GitHub & GitLab nativ

Fügen Sie einmal einen Token hinzu. Bereitstellungsschlüssel und Push-Webhooks werden automatisch für jede App erstellt – self-hosted GitLab inklusive.

Tiefer Tauchgang

RUHE API

Jeder CLI-Befehl ist auch ein HTTP-Endpunkt. Token-Authentifizierung mit fein abgestuften Fähigkeiten, JSON Antworten und asynchrone Jobs mit Statusabfrage.

Tiefer Tauchgang

Gehen Sie CLI Kunde

Die cipi-cli-Binärdatei verwaltet Apps, SSL, Bereitstellungen und Datenbanken von Ihrem Laptop aus – mit Multi-Server-Profile und eine globale Statusübersicht.

Tiefer Tauchgang

Multi-Server-Web GUI

Klicken Sie lieber, als zu tippen? Ein optionales Panel mit 2FA steuert alle Ihre Server von einem einzigen aus Dashboard – ein leichtes Multi-Server-Cockpit auf dem gleichen API.

Tiefer Tauchgang

WHMCS-Abrechnungsmodul

Verkaufen Sie Hosting für Cipi. Kundenaufträge in WHMCS, das Modul stellt bereit, suspendiert und Beendet Apps über das API automatisch.

Tiefer Tauchgang
C

Intelligenz und Überwachung

Cipi Agent

Eine composer-Anforderung in Ihrer Laravel-App schaltet webhook Bereitstellungen, Gesundheitsprüfungen, MCP und vieles mehr frei Anonymisierung. Automatisch erkannt, keine Konfiguration.

Tiefer Tauchgang

MCP Server für KI

Mit sechs Tools können Cursor, VS Code oder Claude Protokolle lesen, die Datenbank abfragen, artisan ausführen und bereitstellen – über HTTPS, mit blockiertem destruktiven SQL.

Tiefer Tauchgang

Gesundheitsendpunkt

Ein JSON-Endpunkt, der PHP-Version, Datenbank, Cache, Warteschlange und Datenträgervitalitäten meldet. Stecken Sie es ein UptimeRobot, Pingdom oder Ihre eigenen Monitore.

Tiefer Tauchgang

E-Mail-Benachrichtigungen

Konfigurieren Sie SMTP einmal und lassen Sie sich über Bereitstellungsfehler, Sicherungsfehler, SSH-Eingriffe usw. benachrichtigen Erhöhungen und wichtige Änderungen. Du schläfst, Cipi Uhren.

Tiefer Tauchgang

Event-Feed

Jedes Bereitstellungs-, Sperr-, Anmelde- und Lebenszyklusereignis landet in einem einzigen Echtzeitprotokoll unter /var/log/cipi/events.log – die Blackbox Ihres Servers.

Tiefer Tauchgang

Jobs, Arbeiter und Planer

Horizon oder einfache Warteschlangenarbeiter unter Supervisor, und der Laravel-Planer ist mit cron verbunden – pro App verwaltet und bei jeder Bereitstellung neu gestartet.

Tiefer Tauchgang
D

Daten & Verteidigung

DB-Sicherung und -Wiederherstellung

Komprimierte Datenbank-Dumps und -Wiederherstellungen in jeweils einem Befehl. Planen Sie sie in cron ein und vergessen Sie es mysqldump-Syntax für immer.

Tiefer Tauchgang

S3 Offsite-Backups

Vollständige App-Backups – Code, Datenbank, .env, Speicher – werden an AWS S3, DO Spaces, MinIO oder versendet Backblaze. Mit automatischem Beschneiden alter Sätze.

Tiefer Tauchgang

Serversynchronisierung A→B

Klonen Sie Apps, Datenbanken, Konfigurationen und SSL-Zertifikate über einen AES-256 auf einen Replikatserver verschlüsselte SSH-Übertragung. Migration wird langweilig.

Tiefer Tauchgang

DSGVO-Anonymisierer

Anonymisierungsregeln pro Tabelle und Spalte erzeugen vollständige Datenbank-Dumps, die durch gefälschte Daten ersetzt werden PII. Echte Struktur, keine persönlichen Daten.

Tiefer Tauchgang

AES-256 Tresor

Alle von Cipi erstellten Anmeldeinformationen – Datenbankkennwörter, Token, Root-Geheimnisse – werden im Ruhezustand verschlüsselt in einem lokalen Tresor. Nichts steht im Klartext.

Tiefer Tauchgang

Standardmäßig gehärtet

Nur-SSH-Schlüsselauthentifizierung, Fail2ban mit progressiven Sperren und einem wiederkehrenden Gefängnis, UFW-Firewall und Unbeaufsichtigte Sicherheitsupgrades – ab der ersten Minute.
