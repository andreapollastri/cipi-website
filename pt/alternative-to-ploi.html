Comparação atualizada em 4 de agosto de 2026 · reflete Cipi 5 e preços/recursos atuais de Ploi

Cipi oferece o mesmo fluxo de trabalho de hospedagem Laravel de um comando que Ploi.io – deploys sem downtime, Laravel Octane, filas, SSL, bancos de dados - mas é 100% gratuito, open source (MIT), roda inteiramente em seu VPS Ubuntu e não tem implantar limites. Troque o GUI por controle total do CLI e automação nativa de IA.

Por que os desenvolvedores mudam de Ploi para Cipi

Sem mensalidade

Ploi cobra de 8 a 30 euros/mês por servidor. Cipi é gratuito para todos os servidores, para sempre — sem níveis de plano, sem atualizações.

Sem limites de deploy

Cipi nunca limita a frequência de deploy. Envie quantos lançamentos desejar em todos os seus aplicativos e servidores.

Sem dependência de SaaS

Ploi controla seus servidores a partir de seu painel. Cipi reside em seu VPS e continua funcionando mesmo se você não tiver acesso ao painel de Internet.

Open source e auditável

Licenciado pelo MIT – leia, audite, bifurque e modifique. Ploi é um SaaS de código fechado.

Nativo de IA, com MCP duplo

Servidores MCP globais e por aplicativo permitem o gerenciamento completo da infraestrutura orientada por IA a partir de qualquer IDE ou agente compatível com MCP.

Criptografia em repouso + soberania

Todas as configurações são criptografadas com AES-256-CBC em seu VPS, e a sincronização de servidor criptografada integrada permite failover automatizado.

Laravel Octane (FrankenPHP)

Crie ou converta apps com cipi app create --octane / cipi app convert --to=octane. Rode o Octane ao lado de apps FPM clássicas, com Horizon e Reverb suportados nativamente — sem nenhum painel SaaS.

Opcional PostgreSQL

MariaDB por padrão; instale o PostgreSQL com um comando e escolha o engine app por app (cipi db install pgsql).

Instalar o Cipi com um comando

Suba um VPS Ubuntu novo e rode:

wget -O - https://cipi.sh/setup.sh | bash

Isso instala e configura o stack de produção completo — Nginx, PHP-FPM / Laravel Octane, MariaDB, PostgreSQL opcional, Redis e Supervisor. Veja o guia de primeiros passos.

Onde Ploi ainda é a melhor escolha

Ploi é baseado na UE (Holanda) e é nativamente compatível com GDPR, com uma web refinada GUI, monitoramento integrado e DNS gerenciamento. Se você deseja uma experiência visual semelhante a Forge por um preço mais baixo e não precisa CLI-primeira automação de pipeline ou integração de IA, Ploi é uma opção forte.

Como migrar de Ploi para Cipi

Mudar de Ploi para Cipi é uma transição limpa, em vez de uma conversão no local: você levanta um novo servidor próximo à sua configuração atual, implante a partir do mesmo repositório Git e alterne DNS quando tudo confere. Sua base de código Laravel não precisa ser alterada.

  1. Faça um inventário no painel Ploi. Liste seus sites, daemons, tarefas cron e bancos de dados para que você possa recriá-los no novo servidor e mantenha Ploi ativo até que a transição seja concluída.
  2. Provisione um VPS Ubuntu novo e instale o Cipi. Serve qualquer provedor (Hetzner, DigitalOcean, Vultr, Linode, AWS). No Ubuntu 24.04/26.04, rode wget -O - https://cipi.sh/setup.sh | bash e o stack de produção completo — Nginx, PHP, MariaDB, Valkey, Supervisor — fica configurado em minutos.
  3. Recrie cada app e conecte o Git. cipi app create provisiona uma app isolada com o seu próprio usuário de sistema, banco de dados, pool PHP e vhost Nginx (adicione --octane para Laravel Octane). Ao conectar GitHub ou GitLab, as deploy keys e os webhooks são configurados automaticamente para deploys sem downtime.
  4. Mova os dados e faça o cutover. Importe o dump do seu banco de dados, reaproveite os seus .env valores, emita os certificados HTTPS com cipi ssl install, aponte o DNS para o novo servidor e desative a instalação antiga.

O Cipi segue as convenções padrão de Nginx, PHP-FPM / Laravel Octane e Deployer, então não sobra nenhuma configuração específica de fornecedor para desfazer depois. Todos os detalhes no guia de primeiros passos.

Perguntas frequentes

Existe uma alternativa gratuita para Ploi?

Sim. Cipi é uma alternativa gratuita, open-source (MIT) e self-hosted para Ploi.io. Ele instala e gerencia um stack de produção Laravel completa em qualquer VPS Ubuntu sem assinatura mensal, sem taxa por servidor e sem limites de deploy.

Qual é a diferença entre Cipi e Ploi?

Ploi é um painel de gerenciamento de servidor SaaS com um GUI sofisticado que custa cerca de € 8/mês por servidor. Cipi é um open-source CLI gratuito que roda inteiramente em seu VPS e adiciona um REST API, um servidor MCP duplo para agentes de IA, criptografia de configuração AES-256 em repouso e sincronização integrada de servidor para servidor.

Cipi tem limites de deploy como alguns níveis gratuitos no estilo Ploi?

Não. Cipi não tem cotas ou limites de deploy de qualquer tipo. Você pode implantar quantas vezes quiser, em quantos servidores e aplicativos desejar, gratuitamente.

Quando ainda devo escolher Ploi?

Escolha Ploi se você deseja uma web refinada GUI, monitoramento integrado e gerenciamento DNS e uma experiência semelhante a Forge por um preço mais baixo, e você não precisa de automação de pipeline CLI-first ou integração de IA.

Posso migrar de Ploi para Cipi?

Sim. Provisione um novo VPS Ubuntu, instale Cipi com um comando, recrie cada site com cipi app create, conecte seu repositório GitHub ou GitLab para deploys sem downtime, importe seu dump de banco de dados e aponte DNS para o novo servidor. Sua própria base de código Laravel não precisa de alterações.

Cipi tem um painel da web como Ploi?

Sim, opcionalmente. Executar cipi gui yourdomain.com instala um painel de controle da web self-hosted gratuito que gerencia um ou mais servidores Cipi a partir do navegador – aplicativos, bancos de dados, SSL, deploys e logs. Ao contrário de Ploi, o painel é opcional e funciona em sua própria infraestrutura; Cipi permanece totalmente utilizável apenas com CLI.
