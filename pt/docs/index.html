Documentação

Cipi Documentação

Documentação técnica completa para Cipi — o Laravel-first open-source implantar CLI. Escolha um capítulo abaixo para começar.

Primeiros passos

Instalação, requisitos, início rápido, stack de tecnologia e estrutura da aplicação para Cipi.

Cipi Agente

Laravel cipi/agent pacote — webhooks, saúde, MCP no aplicativo, anonimizador, modelo de segurança.

Aplicativos

Crie, gerencie, suspenda e configure Laravel aplicativos — incluindo Octane, Reverb e clones — além de aplicativos personalizados.

Implantar & CI/CD

Deploys sem downtime, snapshots de banco de dados pré-implantados, integração Git, CI/CD pipelines, notificações e ambientes de visualização.

Infraestrutura

PHP, bancos de dados, SSL (incl. DNS-01), Horizon, verificações de integridade, backups, workers, firewall, CrowdSec, verificação de integridade e gerenciamento de servidores.

Cliente CLI

Gerencie um ou mais servidores Cipi remotamente a partir do seu terminal local. Aplicativos, bancos de dados, SSL, deploys, perfis de vários servidores, visão geral de status global e conclusão de shell — tudo por meio do REST API.

Avançado

cipi/api REST + MCP + Swagger, sincronização de servidor, cofre, SMTP, retenção de log e configuração avançada.

Cerca de Cipi

História, modelo de segurança, decisões de design e comparação com alternativas.
