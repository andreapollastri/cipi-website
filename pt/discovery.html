Desempenho

Octane em FrankenPHP.
Ou FPM clássico. Sua ligação.

Cada aplicativo escolhe seu mecanismo com um único sinalizador: Laravel Octane rodando em FrankenPHP mantém seu aplicativo inicializado na memória e atende milhares de solicitações por segundo - ou escolha sólido como uma rocha PHP-FPM quando clássico é o que você precisa. Atrás disso, MariaDB ou PostgreSQL por aplicação e Valkey porção cache, sessões e filas diretamente da memória. O desempenho não é um nível pago aqui. É a instalação roteiro.

FrankenPHP Laravel Octane PHP-FPM MariaDB PostgreSQL Valkey

Navio
Navio

git push.
Esse é todo o pipeline.

Conecte GitHub ou GitLab uma vez e Cipi cuida do resto: implantar chaves geradas e injetadas, webhooks criado, cada aplicativo provisionado com seu próprio usuário Linux, banco de dados, vhost e pool PHP-FPM. Empurre para o seu branch e um deploy com assinatura verificada e sem downtime é executada em segundo plano - com um comando reverter se você precisar. Não há CI/CD para manter. Nenhum pipeline YAML para chorar.

Como funcionam os deploys
YAML
cipi.yml

Configuração que viaja com o código.

Faça commit de um arquivo ao lado da app: aliases de domínio, versão PHP e php.ini, bancos extras, queue workers ou Horizon, Laravel Reverb, o scheduler, um healthcheck e perfis de backup. Gere-o a partir do servidor, inspecione o plano, aplique — ou ative o opt-in para que cada deploy bem-sucedido reconcilie. O schema não carrega comandos shell; um arquivo inválido é rejeitado por inteiro, nunca aplicado pela metade.

generate plan apply auto on deploy

Ao vivo
Sempre ligado

Filas, websockets, cron.
Já está em execução.

Horizon ou workers de fila simples são executados em Supervisor e reiniciam automaticamente em cada deploy. Laravel Reverb envia websockets em tempo real através de Nginx com SSL. O agendador está conectado ao cron no momento o aplicativo é criado. Trabalhos em segundo plano, transmissões e tarefas agendadas não são uma reflexão tardia — eles são parte do provisionamento.

AI
IA nativa

Sua IA tem um linha direta para a produção.

O servidor MCP integrado conecta Cursor, VS Code ou Claude Desktop diretamente ao seu aplicativo ao vivo através de HTTPS. Faça perguntas em linguagem natural: leia logs, execute consultas SQL, execute comandos artisan, acione implanta. Instruções destrutivas são bloqueadas, nenhuma sessão SSH é aberta e você nunca cola um stack rastrear em uma janela de bate-papo novamente.

saúde app_info logs db_query artisan implantar
Conheça o servidor MCP
Seguro
Fortaleza

Endurecido antes do seu primeiro login.

Autenticação somente com chave SSH, Fail2ban com banimento progressivo, firewall UFW, segurança autônoma atualizações, um cofre AES-256 para cada credencial, retenção de log compatível com GDPR e suporte completo para usuários do Linux isolamento por aplicativo. Alertas de e-mail são acionados em tentativas de invasão, elevações de sudo, alterações de chave SSH e deploys com falha – enquanto tudo cai em um log de eventos inviolável. Segurança não é um recurso que você habilitar. É o padrão que você teria que trabalhar para remover.

Resiliência

Perder um servidor custa para você um comando.

Código, banco de dados, .env e armazenamento — criptografados e enviados para qualquer bucket compatível com S3 dentro do prazo. Restaure um banco de dados em um comando e reverta uma versão em outro. E quando chegar a hora de migrar ou recuperar, cipi sync clona aplicativos, bancos de dados, configurações e certificados SSL para um novo servidor através de um único AES-256 criptografado transferência. A recuperação de desastres deixa de ser um projeto e passa a ser um comando.

S3 · Espaços · MinIO · Backblaze restauração com um comando sincronização do servidor A → B

Provisão e Desempenho

Instalação com um comando

Um único script transforma um novo VPS Ubuntu em um stack de produção completo: Nginx, PHP 8.5, MariaDB ou PostgreSQL, Valkey, Supervisor, Deployer, Certbot.

Mergulho profundo

Octane em FrankenPHP

Sirva cada aplicativo em Laravel Octane com tecnologia FrankenPHP para velocidade bruta ou no clássico PHP-FPM testado em batalha. Uma bandeira por aplicativo, você decide.

Mergulho profundo

MariaDB ou PostgreSQL

MariaDB por padrão, PostgreSQL a um comando de distância. Escolha o mecanismo por aplicativo – .env e conexão URLs seguem automaticamente.

Mergulho profundo

Valkey cache e filas

Um armazenamento na memória compatível com Redis para cache, sessões e filas — instalado, protegido e conectado a todos os aplicativos prontos para uso.

Mergulho profundo

Horizon e Reverb

Laravel Horizon observando suas filas e Reverb websockets atrás de Nginx com SSL — provisionado e supervisionado para você.

Mergulho profundo

Aplicativos totalmente isolados

Cada aplicativo recebe seu próprio usuário Linux, banco de dados, Nginx vhost, pool PHP-FPM e workers. Um aplicativo comprometido nunca toca em outro.

Mergulho profundo

Deploys sem downtime

Versões atômicas baseadas em Deployer com comutação de link simbólico e reversão de um comando. Seus usuários nunca veja uma página de manutenção.

Mergulho profundo

git push auto-deploy

Webhooks verificados por assinatura HMAC acionam deploys em segundo plano a cada push. Filtragem de ramificação incluído, tubulação CI/CD não necessária.

Mergulho profundo

cipi.yml

Configuração que acompanha o código: aliases, PHP, bancos de dados, workers, Reverb, agendador, verificação de integridade e backups — planejados, aplicados ou reconciliados em cada deploy.

Mergulho profundo

Automático SSL

Let's Encrypt certificados instalados e renovados automaticamente — domínios wildcard suportados. HTTPS é um comando, então é para sempre.

Mergulho profundo

Mergulho profundo

Web multiservidor GUI

Prefere clicar a digitar? Um painel opcional com 2FA aciona todos os seus servidores a partir de um único dashboard — um cockpit multiservidor leve em cima do mesmo API.

Inteligência e Monitoramento

Cipi Agente

Uma necessidade composer dentro do seu aplicativo Laravel desbloqueia deploys webhook, verificações de integridade, MCP e anonimato. Descoberto automaticamente, configuração zero.

Mergulho profundo

servidor MCP para IA

Seis ferramentas permitem que Cursor, VS Code ou Claude leiam logs, consultem o banco de dados, executem artisan e implantem — acima de HTTPS, com SQL destrutivo bloqueado.

Mergulho profundo

Ponto de extremidade de integridade

Um endpoint JSON reportando versão PHP, banco de dados, cache, fila e sinais vitais de disco. Conecte-o UptimeRobot, Pingdom ou seus próprios monitores.

Mergulho profundo

Alertas por e-mail

Configure o SMTP uma vez e seja notificado sobre falhas de deploy, erros de backup, intrusões SSH, sudo elevações e mudanças importantes. Você dorme, Cipi vigia.

Mergulho profundo

Feed de eventos

Cada evento de deploy, banimento, login e ciclo de vida chega a um único registro em tempo real em /var/log/cipi/events.log — a caixa preta do seu servidor.

Mergulho profundo

Empregos, workers e agendador

Horizon ou workers de fila simples em Supervisor, e o agendador Laravel conectado a cron — gerenciado por aplicativo e reiniciado em cada deploy.

Mergulho profundo

Dados e Defesa

Backup e restauração de banco de dados

Dumps e restaurações de banco de dados compactado em um comando cada. Agende-os em cron e esqueça Sintaxe mysqldump para sempre.

Mergulho profundo

S3 backups externos

Backups completos de aplicativos — código, banco de dados, .env, armazenamento — enviados para AWS S3, DO Spaces, MinIO ou Contra-chama. Com poda automática de conjuntos antigos.

Mergulho profundo

Sincronização do servidor A → B

Clone aplicativos, bancos de dados, configurações e certificados SSL para um servidor de réplica por meio de um AES-256 transferência SSH criptografada. A migração tornou-se enfadonha.

Mergulho profundo

Anonimizador GDPR

Regras de anonimato por tabela e por coluna produzem dumps completos do banco de dados com substituição de dados falsos PII. Estrutura real, zero dados pessoais.

Mergulho profundo

AES-256 cofre

Cada credencial Cipi criada – senhas de banco de dados, tokens, segredos de raiz – é criptografada em repouso em um cofre local. Nada fica em texto simples.

Mergulho profundo

Endurecido por padrão

Autenticação somente com chave SSH, Fail2ban com proibições progressivas e prisão recidiva, firewall UFW e atualizações de segurança autônomas — desde o primeiro minuto.
