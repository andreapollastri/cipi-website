Ploi Cloud alternativa

A self-hosted alternativa ao Ploi Cloud

Comparação atualizada em 7 de setembro de 2026 · reflete Cipi 5 e preços/recursos atuais do Ploi Cloud

Ploi Cloud (ploi.cloud) é um PaaS Laravel/PHP/Node europeu — preços baseados em memória, Amsterdã/Londres/Chicago, MCP e CLI — e não é o mesmo produto que o Ploi.io (o painel de servidor). Cipi é o oposto self-hosted: você possui um VPS em qualquer provedor, com acesso root completo, um custo fixo previsível e sem dependência de fornecedor. Gratuito, open source e totalmente orientado para CLI.

Por que as equipes escolhem Cipi em vez de Ploi Cloud

Custo previsível e fixo

Cipi é gratuito; você paga apenas pelo VPS. O Ploi Cloud cobra €13,88 por GB de memória (a CPU escala com a RAM) — simples, ainda uma fatura hospedada que cresce com as instâncias.

Você possui o servidor

Root completo em qualquer provedor. O Ploi Cloud executa seu app na nuvem europeia (e Chicago) deles — você não recebe a máquina.

Sem vendor lock-in

Cipi usa um stack padrão portátil Ubuntu + Nginx + PHP-FPM / Laravel Octane + MariaDB (opcional PostgreSQL) + Supervisor que você pode reproduzir em qualquer lugar.

Profundidade Laravel em um stack nativo

Octane, Horizon, Reverb, Deployer e filas são recursos CLI de primeira classe. O Ploi Cloud é um PaaS amigável ao Laravel, não uma CLI de gerenciamento de servidor que você pode auditar.

Open source e nativo de IA

Licenciado pelo MIT e auditável, com um servidor duplo MCP. O Ploi Cloud também envia MCP e uma CLI — no plano de controle deles.

Criptografia em repouso + soberania

Todas as configurações criptografadas com AES-256-CBC em um VPS na região que você escolher. O Ploi Cloud é hospedagem UE orientada a GDPR; Cipi nunca envia dados de infraestrutura para fora da caixa.

Laravel Octane (FrankenPHP)

Crie ou converta apps com cipi app create --octane / cipi app convert --to=octane. Execute Octane ao lado de aplicativos FPM clássicos no mesmo servidor.

Não é o mesmo que o Ploi.io

Precisa de um painel que gerencia o seu VPS em vez de um PaaS? Veja a comparação dedicada Cipi versus Ploi.io — produto diferente, compensações diferentes.

Instalar o Cipi com um comando

Suba um VPS Ubuntu novo e rode:

wget -O - https://cipi.sh/setup.sh | bash

Isso instala e configura o stack de produção completo — Nginx, PHP-FPM / Laravel Octane, MariaDB, PostgreSQL opcional, Redis e Supervisor. Veja o guia de primeiros passos.

Onde Ploi Cloud é a melhor escolha

O Ploi Cloud vence em gerenciamento zero de servidor com um PaaS europeu consciente de Laravel: deploys git-push, SSL automático, auto-scaling, bancos gerenciados (MySQL, PostgreSQL, Redis, Valkey, MongoDB, MinIO), Amsterdã/Londres/Chicago, GDPR por design, MCP e CLI. Se você quer residência de dados na UE como serviço e não quer possuir um VPS, o Ploi Cloud é a melhor opção. Se você já usa o Ploi.io para gerenciar servidores, Cloud é o runtime hospedado deles — Cipi substitui o lado “possuir o VPS” dessa história.

Como migrar do Ploi Cloud para Cipi

Mudar do Ploi Cloud para Cipi é uma transição limpa, em vez de uma conversão no local: você levanta um novo servidor ao lado da configuração atual, implanta a partir do mesmo repositório Git e altera o DNS quando tudo confere. Sua base de código Laravel não precisa ser alterada.

  1. Exporte seus dados do Ploi Cloud. Faça dump do banco gerenciado, anote variáveis de ambiente, workers e o tamanho de memória/instância que você pagava para dimensionar o novo VPS.
  2. Provisione um VPS Ubuntu novo e instale o Cipi. Serve qualquer provedor (Hetzner, DigitalOcean, Vultr, Linode, AWS). No Ubuntu 24.04/26.04, rode wget -O - https://cipi.sh/setup.sh | bash e o stack de produção completo — Nginx, PHP, MariaDB, Valkey, Supervisor — fica configurado em minutos.
  3. Recrie cada app e conecte o Git. cipi app create provisiona uma app isolada com o seu próprio usuário de sistema, banco de dados, pool PHP e vhost Nginx (adicione --octane para Laravel Octane). Ao conectar GitHub ou GitLab, as deploy keys e os webhooks são configurados automaticamente para deploys sem downtime.
  4. Mova os dados e faça o cutover. Importe seu dump de banco de dados, copie seus valores .env, emita certificados HTTPS com cipi ssl install, aponte o DNS para o novo servidor e desative a configuração antiga.

Cipi usa convenções padrão Nginx, PHP-FPM / Laravel Octane e Deployer, portanto não há configuração específica do fornecedor para desfazer depois. Detalhes completos no guia de primeiros passos.

Perguntas frequentes

Ploi Cloud é o mesmo que Ploi.io?

Não. Ploi.io é um painel SaaS que gerencia servidores que você possui. Ploi Cloud (ploi.cloud) é um PaaS europeu hospedado com preços baseados em memória. Cipi é uma alternativa self-hosted a ambos: veja também Cipi versus Ploi.io.

Existe uma alternativa self-hosted ao Ploi Cloud?

Sim. Cipi é uma alternativa gratuita, open-source (MIT) e self-hosted ao Ploi Cloud. Em vez de um PaaS Laravel/PHP gerenciado, você possui um VPS em qualquer provedor e Cipi instala e gerencia toda o stack de produção nele.

Qual é a diferença entre Cipi e Ploi Cloud?

Ploi Cloud é um PaaS totalmente gerenciado, precificado por memória, em Amsterdã, Londres e Chicago, com MCP e uma CLI. Cipi é executado no seu próprio VPS com acesso root completo e um custo fixo, é open source e adiciona Laravel Octane, um servidor MCP duplo e criptografia de configuração em repouso.

Cipi é mais barato que o Ploi Cloud?

Cipi em si é gratuito; seu único custo é o VPS. O Ploi Cloud cobra €13,88 por GB de memória por mês. Uma instância Cloud pequena pode custar mais que um VPS equivalente mais Cipi gratuito.

Quando ainda devo escolher o Ploi Cloud?

Escolha o Ploi Cloud se quiser hospedagem gerenciada europeia em primeiro lugar, deploys git-push, auto-scaling e bancos gerenciados sem executar um VPS, e se sentir confortável com faturamento baseado em memória.

Posso migrar do Ploi Cloud para Cipi?

Sim. Provisione um VPS Ubuntu, instale Cipi, crie o aplicativo com cipi app create (adicione --octane para continuar executando Octane), restaure o dump do banco, copie valores de ambiente e aponte o DNS. Você troca o faturamento PaaS por um custo VPS fixo.
