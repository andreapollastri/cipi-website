Deploy de Laravel, sem atrito.

CLI open source pensada primeiro para Laravel, com IA e MCP — e também para sites estáticos e PHP genérico. Um comando instala o stack. Um comando cria uma app isolada com banco de dados, workers, SSL e deploys sem downtime.

Começar Descoberta
cipi · configuração
# Fresh Ubuntu 24.04 or 26.04 VPS
$ wget -O - https://cipi.sh/setup.sh | bash

# Create an app
$ cipi app create myapp --domain=myapp.com --php=8.5

OK  Nginx · PHP-FPM / Octane · MariaDB · SSL · Deployer

Opcional

Uma API REST prática,
quando você precisar.

O Cipi continua CLI-first por padrão — mas na hora de automatizar, integrar ou deixar agentes de IA gerenciarem os seus servidores, ative a camada de API opcional com um único comando. Use a REST API para criar e gerenciar várias aplicações em toda a sua infraestrutura a partir de um único endpoint. O Cliente CLI (cipi-cli) leva a API inteira para o seu terminal local — gerencie apps, bancos de dados, SSL e deploys sem SSH. Um servidor MCP global permite criar e gerenciar a sua infraestrutura pelos seus agentes de IA, e um módulo de provisioning do WHMCS oficial cria e encerra apps automaticamente a partir do seu painel de faturamento.

Integração de faturamento

Venda hospedagem com
WHMCS, movido a Cipi.

Transforme o seu servidor Cipi num negócio de hospedagem. O módulo oficial de provisioning para WHMCS liga o seu painel de faturamento à API REST do Cipi — quando um cliente contrata um produto, a app é criada automaticamente. Encerrar, suspender, reativar: tudo vai do WHMCS para o seu servidor, sem uma única sessão SSH.

  • Provisioning totalmente automático — o cliente contrata e a app entra no ar
  • Tipos de app Laravel e personalizados, com versão de PHP e configurações de Git por produto
  • Processamento assíncrono de jobs com polling de status — sem timeouts de HTTP
  • Autenticação por token Bearer, com permissões granulares por ability
  • Teste de conexão embutido — confira se a API responde direto do admin do WHMCS
  • Open source, licença MIT — estenda ou use em white label como precisar

Gerenciamento remoto

O seu servidor,
de qualquer terminal.

cipi-cli é um binário Go independente que conversa com a API REST do Cipi a partir da sua máquina local. Sem SSH — gerencie apps, bancos de dados, certificados SSL e deploys de qualquer terminal. Disponível para Linux e macOS.

  • Ciclo de vida completo da app — criar, editar, fazer deploy e excluir da sua máquina
  • Gerenciamento de bancos de dados — criar, fazer backup, restaurar e rotacionar senhas
  • Provisioning de SSL — instale certificados Let's Encrypt com um único comando
  • Perfis multiservidor — um perfil por servidor, troca por prefixo
  • Visão global do status — CPU, RAM, disco, apps e serviços em todos os servidores
  • Aliases de domínio — adicionar, listar e remover aliases por app
  • Autocomplete de shell — instalação com um comando para zsh, bash e fish
  • Saída JSON — canalize para jqpara scripts e pipelines CI/CD
  • Open source, licença MIT — binários prontos ou compilação a partir do código-fonte

Painel web opcional

Uma GUI, só se
você quiser uma.

O Cipi é CLI-first — e vai continuar sendo. Mas se um dashboard no navegador servir melhor para você ou para os seus clientes, um único comando instala o painel de controle web opcional: uma app Laravel self-hosted que gerencia um ou vários servidores Cipi pela mesma API REST. Não precisa? Não instale — nada muda.

  • Um único comando para instalar — cipi gui panel.example.com
  • Gerencie apps, SSL, logs e bancos de dados pelo navegador
  • Um painel, muitos servidores — um cockpit multiservidor leve
  • Login por sessão, com autenticação de dois fatores TOTP opcional
  • Self-hosted e open source — o seu painel, o seu servidor, os seus dados
  • Desinstale a qualquer momento — cipi gui remove — e você volta à CLI pura

Perguntas frequentes

As perguntas de sempre antes de instalar

O que é Cipi?

O Cipi é uma CLI de deploy open source pensada primeiro para Laravel, que também suporta sites estáticos e aplicações PHP genéricas. Um único comando instala um stack de produção completo (Nginx, PHP-FPM ou Laravel Octane, MariaDB, Valkey, Supervisor) em qualquer VPS Ubuntu.

Cipi é gratuito?

Sim. O Cipi é 100% gratuito e open source, sob licença MIT. Você mesmo o hospeda no seu servidor, sem assinatura e sem taxas por servidor.

Como faço para instalar Cipi?

Rode um único comando num VPS Ubuntu recém-criado: wget -O - https://cipi.sh/setup.sh | bash. Ele instala e configura automaticamente todo o stack de produção LEMP.

O Cipi é uma alternativa ao Laravel Forge?

Sim. O Cipi é uma alternativa gratuita, self-hosted e open source ao Laravel Forge e a ferramentas de deploy semelhantes, com controle total dos seus servidores e custo recorrente zero. Veja a comparação com o Laravel Forge.

Quais servidores Cipi suporta?

Cipi é executado em qualquer VPS Ubuntu de provedores como DigitalOcean, Hetzner, Vultr, Linode, AWS e muito mais, transformando um único servidor em uma plataforma de hospedagem LEMP com vários aplicativos.

Cipi suporta Laravel Octane?

Sim. Cipi executa Laravel Octane em FrankenPHP nativamente: crie aplicativos Octane com cipi app create --octane ou converta aplicativos existentes com cipi app convert --to=octane, executado junto com aplicativos PHP-FPM clássicos no mesmo servidor.

Cipi tem um painel de controle web?

Sim, opcionalmente. Cipi é CLI-first, mas cipi gui yourdomain.com instala um painel da web self-hosted gratuito que gerencia um ou mais servidores Cipi a partir do navegador – aplicativos, bancos de dados, SSL, deploys e logs.

Os agentes de IA podem gerenciar um servidor Cipi?

Sim. Cipi fornece um servidor MCP (Model Context Protocol) duplo, para que IDEs e agentes de IA compatíveis com MCP possam criar aplicativos, executar deploys, gerenciar SSL e bancos de dados por meio de um API estruturado.
