Documentazione

Documentazione Cipi

Documentazione tecnica completa di Cipi — la CLI open source per il deploy Laravel-first. Scegli un capitolo qui sotto per iniziare.

Primi passi

Installazione, requisiti, avvio rapido, tech stack e struttura app per Cipi.

Cipi Agent

Package Laravel cipi/agent — webhook, health, MCP in-app, anonymizer, modello di sicurezza.

App

Crea, gestisci, sospendi e configura app Laravel — incluse Octane, Reverb e clone — oltre ad applicazioni personalizzate.

Deploy e CI/CD

Deploy zero-downtime, snapshot DB pre-deploy, integrazione Git, pipeline CI/CD, notifiche e ambienti preview.

Infrastruttura

PHP, database, SSL (incl. DNS-01), Horizon, healthcheck, backup, worker, firewall, CrowdSec, scansione di integrità e gestione server.

Client CLI

Gestisci uno o più server Cipi da remoto dal tuo terminale locale. App, database, SSL, deploy, profili multi-server, panoramica globale dello stato e shell completion — tutto via REST API.

Avanzato

cipi/api REST + MCP + Swagger, sync server, vault, SMTP, retention log e configurazione avanzata.

Storia, modello di sicurezza, decisioni di design e confronto con le alternative.
