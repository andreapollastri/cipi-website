Opzionale

REST API comoda
quando ti serve.

Cipi resta CLI-first di default — ma quando vuoi automatizzare, integrare o lasciare che gli agenti AI gestiscano il server globalmente, abilita il layer API opzionale con un solo comando. Usa la REST API per creare e gestire più applicazioni nell'infrastruttura da un unico endpoint. Il Client CLI (cipi-cli) porta l'API completa al terminale locale — gestisci app, database, SSL e deploy senza SSH. Un server MCP globale è disponibile per creare e gestire l'infrastruttura tramite i tuoi agenti AI, e un modulo di provisioning WHMCS ufficiale crea e termina app automaticamente dal pannello di fatturazione.

Vendi hosting con
WHMCS, powered by Cipi.

Trasforma il tuo server Cipi in un business di hosting. Il modulo di provisioning WHMCS ufficiale collega il pannello di fatturazione alla REST API di Cipi — quando un cliente ordina un prodotto, l'app viene creata automaticamente. Termina, sospendi, riattiva — tutto fluisce da WHMCS al server senza una singola sessione SSH.

  • Provisioning completamente automatizzato — il cliente ordina, l'app va online
  • Tipi app Laravel e personalizzate con versione PHP e impostazioni Git per prodotto
  • Gestione job asincrona con polling dello stato — nessun timeout HTTP
  • Autenticazione Bearer token con permessi granulari per ability
  • Test Connection integrato — valida la raggiungibilità API da WHMCS Admin
  • Open source, licenza MIT — estendi o white-label come preferisci

Gestione remota

Il tuo server,
da qualsiasi terminale.

cipi-cli è un binario Go standalone che comunica con la REST API di Cipi dalla tua macchina locale. Nessun SSH necessario — gestisci app, database, certificati SSL e deployment da qualsiasi terminale. Disponibile per Linux e macOS.

  • Ciclo di vita completo dell'app — crea, modifica, deploy ed elimina dalla tua macchina
  • Gestione database — crea, backup, restore e rotazione password
  • Provisioning SSL — installa certificati Let's Encrypt con un solo comando
  • Profili multi-server — un profilo per server, cambia con un prefisso
  • Panoramica globale dello stato — CPU, RAM, disco, app e servizi su tutti i server
  • Alias di dominio — aggiungi, elenca e rimuovi alias per app
  • Shell completion — installazione con un solo comando per zsh, bash e fish
  • Output JSON — pipe verso jq per script e pipeline CI/CD
  • Open source, licenza MIT — binari precompilati e build da sorgente

FAQ

Domande prima di installare

Cos'è Cipi?

Cipi è una CLI di deploy open source Laravel-first che supporta anche siti statici e app PHP generiche. Un solo comando installa uno stack di produzione completo (Nginx, PHP-FPM o Laravel Octane, MariaDB, Valkey, Supervisor) su qualsiasi VPS Ubuntu.

Cipi è gratuito?

Sì. Cipi è gratuito al 100% e open source con licenza MIT. Lo self-hosti sul tuo server senza abbonamento né costi per server.

Come installo Cipi?

Esegui un solo comando su un VPS Ubuntu nuovo: wget -O - https://cipi.sh/setup.sh | bash. Installa e configura automaticamente lo stack LEMP di produzione completo.

Cipi è un'alternativa a Laravel Forge?

Sì. Cipi è un'alternativa gratuita, self-hosted e open source a Laravel Forge e strumenti di deploy simili, con controllo completo sui server e zero costi ricorrenti. Vedi il confronto con Laravel Forge.

Quali server supporta Cipi?

Cipi gira su qualsiasi VPS Ubuntu di provider come DigitalOcean, Hetzner, Vultr, Linode, AWS e altri, trasformando un singolo server in una piattaforma di hosting LEMP multi-app.

Cipi supporta Laravel Octane?

Sì. Cipi esegue Laravel Octane su FrankenPHP in modo nativo: crea app Octane con cipi app create --octane o converti app esistenti con cipi app convert --to=octane, affiancate ad app PHP-FPM classiche sullo stesso server.

Cipi ha un pannello di controllo web?

Sì, opzionalmente. Cipi è CLI-first, ma cipi gui yourdomain.com installa una dashboard web gratuita e self-hosted che gestisce uno o più server Cipi dal browser — app, database, SSL, deploy e log.

Gli agenti AI possono gestire un server Cipi?

Sì. Cipi include un doppio server MCP (Model Context Protocol), così IDE e agenti AI compatibili con MCP possono creare app, eseguire deploy, gestire SSL e database tramite un'API strutturata.
